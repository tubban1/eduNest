## 一句话结论（先给你判断标准）

> **教育场景（尤其是 K12）首要目标不是“好看”，而是：
> 👀 不累眼 + 🧠 不干扰认知 + 😌 长时间安心使用**

所以结论是：

> ✅ **低饱和度、冷暖平衡、以“稳定感”为主的配色最合适**

---

## 一、教育产品配色的 5 条铁律（很重要）

### 1️⃣ 降低视觉负担（第一优先级）

* 避免：

  * 高饱和纯色（#FF0000、#00FF00）
  * 大面积对比色
* 选择：

  * **低饱和蓝 / 青 / 灰**
  * 背景偏暖白而不是纯白

📌 原因：
孩子一节课 30–45 分钟，**眼睛疲劳就是流失率**

---

### 2️⃣ 情绪要“稳”，不能“嗨”

教育 ≠ 游戏首页

| 情绪 | 适合？ | 原因   |
| -- | --- | ---- |
| 兴奋 | ❌   | 干扰理解 |
| 紧张 | ❌   | 数学焦虑 |
| 平静 | ✅   | 有利理解 |
| 好奇 | ✅   | 适度引导 |

👉 配色目标：**“安静的专注感”**

---

### 3️⃣ 色彩只用于「结构与引导」，不是装饰

在教育产品中，颜色应该主要用于：

* 当前学习节点（高亮）
* 正确 / 错误反馈
* 层级结构（树 / 知识图谱）
* 可操作元素（按钮、交互）

🚫 不要：

* 给每个模块一个炫色
* 用颜色“堆设计感”

---

### 4️⃣ 不同年龄，饱和度不同

| 年龄段 | 建议               |
| --- | ---------------- |
| 小学  | 稍高饱和 + 明确色块      |
| 初中  | **中低饱和（你现在的核心）** |
| 高中  | 更偏学术、冷静          |

你现在做的是 **初中 → K12**
👉 **一定要从“初中安全配色”起步**

---

### 5️⃣ 数学场景：颜色必须“理性”

数学对颜色特别敏感：

* 颜色太强 → 干扰符号
* 颜色太杂 → 破坏结构

👉 **数学 UI 的颜色应该像教科书，不像营销页**

---

## 二、我给你一套「可直接用」的教育级配色方案

### 🎯 主色（Primary）

**低饱和蓝 / 静谧蓝**

```text
Primary: #3A6EA5   // 稳定、理性、可信
```

用于：

* 主要按钮
* 当前学习节点
* 选中状态

---

### 🌿 辅助色（Secondary）

**柔和青绿（缓解数学紧张感）**

```text
Secondary: #4FB3A2
```

用于：

* 正确反馈
* 进度条
* 成就/完成状态

---

### 🧠 强调色（Accent，少量使用）

**低饱和橙 / 琥珀**

```text
Accent: #F2A65A
```

用于：

* 提示
* 重点提醒
* 下一步引导

⚠️ **不用于大面积背景**

---

### ❌ 错误 / 警告色（一定要克制）

```text
Error: #D9534F
Warning: #F0AD4E
```

仅用于：

* 答错反馈
* 系统异常提示

---

### 📄 背景与文字（非常关键）

```text
Background: #F7F8FA   // 非纯白，护眼
Card:       #FFFFFF
Text Main:  #2E2E2E
Text Sub:   #6B7280
Border:     #E5E7EB
```

---

## 三、映射到你现在的「双索引学习结构」

### 学习路径（左侧树）

* 背景：浅灰
* 当前节点：Primary 蓝
* 未解锁：灰 + 低对比
* 已完成：Secondary 绿

---

### 知识图谱（右侧 / 脑图）

* 主节点：Primary
* 关联节点：Secondary
* 当前焦点：Primary + 描边
* 非焦点：灰化（opacity 0.4–0.6）

👉 颜色在这里是**认知工具，不是装饰**

---

## 四、你这个项目「绝对不要」用的配色

| 类型     | 原因          |
| ------ | ----------- |
| 霓虹色    | 破坏专注        |
| 高对比黑白  | 眼疲劳         |
| 彩虹配色   | 数学灾难        |
| 暗黑模式默认 | K12 不友好（可选） |

> **“我们采用的是教科书级、长期学习友好的配色体系，
> 颜色的任务是引导认知，而不是吸引注意力。”**
