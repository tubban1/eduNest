## 📚 不同学科下的知识点呈现方式

| 学科            | 特点        | 知识点呈现方式                       |
| ------------- | --------- | ----------------------------- |
| **数学**        | 结构严密、逻辑强  | 概念卡、公式模块、知识树、题型关联、互动演练（计算/推理） |
| **语文 / 中文**   | 语言丰富、语义复杂 | 词语卡片、语法标签、阅读理解图谱、造句练习、拼音-汉字映射 |
| **英语**        | 多模态、强调语境  | 单词记忆卡、发音示例、词根/词缀、例句联想、图片/视频辅助 |
| **物理/化学**     | 实验驱动、原理抽象 | 实验图示、公式模块、模拟动画、因果图、概念网        |
| **历史 / 地理**   | 时间轴、空间地图  | 年代表、地图标记、事件因果图、人物关系图          |
| **编程 / 信息技术** | 代码导向      | 代码片段、模块依赖图、输入输出示意图、可运行组件      |

---

## 🧠 不同认知深度的知识点展示方式（对应布鲁姆认知层次）

| 层级     | 示例        | 呈现方式            |
| ------ | --------- | --------------- |
| **记忆** | 词汇、定义、定理  | 闪卡、关键词提示、配对练习   |
| **理解** | 解释公式、翻译句子 | 示例、类比、动画展示      |
| **应用** | 解题、造句、运算  | 实践题、填空、步骤演示     |
| **分析** | 找出错误、拆分结构 | 拆解图、对比图、逻辑框图    |
| **评价** | 判断是否正确    | 多选判断、理由填写       |
| **创造** | 写作文、写程序   | 自由创作、结构引导、自评+互评 |

---

## 🎓 不同学习方式下的知识点展现

| 学习方式      | 示例         | 知识点呈现方式            |
| --------- | ---------- | ------------------ |
| **主动学习**  | 自主探索、提问、表达 | 知识图谱导航、思维导图、开放问题引导 |
| **被动学习**  | 视频、讲解、文本阅读 | 视频章节标签、PPT结构图、文本高亮 |
| **互动学习**  | 小组、问答、角色扮演 | 多人答题、辩论话题卡、角色卡片    |
| **游戏化学习** | 闯关、PK、奖励   | 关卡知识标签、积分知识图、成就系统  |
| **实验学习**  | 操作、验证      | 模拟实验室、拖拽组件、参数调试框   |

## 🔁 跨学科 & 融合知识点展示

| 类型             | 示例         | 呈现方式                   |
| -------------- | ---------- | ---------------------- |
| **项目式学习（PBL）** | 写新闻稿、建生态模型 | 多学科关联标签、阶段任务卡、任务-知识关联图 |
| **STEAM 教育**   | 编程+美术+数学   | 多维内容展示：代码+图形+数学关系网     |

## 📈 附加维度：用户角度的展示方式

| 维度         | 展现方式            |
| ---------- | --------------- |
| **学习进度**   | 进度条、完成度、复习建议    |
| **掌握情况**   | 掌握度评级、错题率统计     |
| **关联内容推荐** | 下一步知识点、易混点对比    |
| **能力地图**   | 知识点覆盖热力图、技能树    |
| **个性化路径**  | AI推荐学习路径、跳跃学习入口 |

---

## ✅ 小结

| 维度   | 展示思路                       |
| ---- | -------------------------- |
| 学科差异 | 用适合该学科的图形、模块、互动工具          |
| 深度维度 | 匹配布鲁姆层级，控制信息量和交互程度         |
| 学习方式 | 用动态组件和结构，满足主动/被动/游戏化等需求    |
| 用户角色 | 针对学生、教师、家长、系统管理者不同目的定制展示方式 |
