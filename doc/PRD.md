# 产品需求文档（PRD）

## 项目名称

AI 互动教育平台 MVP

## 项目概述

该平台致力于为教育场景提供以 AI 驱动的互动式教学内容生成与使用服务。核心能力包括基于自然语言提示生成 Vue 渲染代码，通过前端交互展示教学内容。MVP 阶段聚焦于 Admin 教师内容创建与用户知识点浏览。

## 核心目标

* 管理端通过自然语言提示生成 Vue 教学互动效果并保存
* 渲染结果自动分类打上知识点标签
* 用户端可浏览所有互动内容，并可评分、分享、保存
* 所有用户行为通过 Umami API 进行追踪分析

---

## MVP 功能范围

### 1. Admin 教师端

* 登录后输入提示生成 Vue 代码
* 实时预览互动效果
* 标注知识点标签并保存

### 2. 用户端（无需登录）

* 浏览所有已发布的互动教学内容
* 根据年级、学科或知识点筛选内容
* 对每个内容进行评分和分享

### 3. 用户行为追踪

* 页面访问、点击、评分等行为通过 Umami API 记录
* 所有交互事件绑定匿名 ID 或登录用户 ID

## 非 MVP（后续版本）

* 用户登录/注册/保存收藏列表
* AI 协助修改、改错、优化代码
* 用户通过指令生成或优化已有内容
* 自动生成数据库 schema 记录用户互动成绩等
* 内容审核机制
* 支付系统与付费内容访问
* 多样化知识点管理方式（见下）

## 数据结构（基于用户故事重构）

### 表：`content`

| 字段               | 类型        | 描述             |
| ---------------- | --------- | -------------- |
| id               | UUID(short) | 主键             |
| title            | string    | 互动标题           |
| code\_html       | text      | Vue 代码 HTML 部分 |
| code\_css        | text      | CSS 部分         |
| code\_js         | text      | JS 部分          |
| knowledge\_point | string\[] | 知识点标签          |
| language         | string    | 内容语言（用于学习）     |
| created\_by      | UUID      | 创建者用户 ID       |
| created\_at      | timestamp | 创建时间           |
| updated\_at      | timestamp | 更新时间           |

### 表：`user_collections`

| 字段             | 类型        | 描述                       |
| -------------- | --------- | ------------------------ |
| id             | UUID      | 主键                       |
| user\_id       | UUID      | 用户 ID                    |
| content\_id    | UUID      | 收藏的内容 ID                 |
| list\_path     | text      | 嵌套列表路径（如 "数学 > 几何 > 错题"） |
| tags           | string\[] | 用户自定义标签（如“复习”、“易错”）      |
| status         | string    | 学习状态（详见用户故事）             |
| timeline\_date | date      | 时间线中的时间节点（可为空）           |
| added\_at      | timestamp | 收藏时间                     |

### 表：`users`（Supabase 默认）

用于管理注册用户，包括 Admin 教师。

## 核心交互流程

1. **Admin 端内容创建流程**：

   * 登录 → 输入提示 → AI 生成 Vue 代码 → 查看预览 → 添加知识点标签与语言 → 保存

2. **用户端浏览流程**：

   * 打开网站 → 浏览/筛选知识点 → 体验互动内容 → 可评分或分享

3. **用户收藏与管理流程**：

   * 收藏内容 → 加入某个嵌套列表路径 → 添加标签与状态 → 时间线计划（可选）

4. **Umami 追踪流程**：

   * 所有页面加载、点击交互、评分行为通过 API 请求记录至 Umami Cloud

---

## 知识点管理方式（支持多种并存，归属于用户交互模块）

1. **标签管理（Tag-based）**：

   * 灵活搜索、可交叉分类，适合快速归类

2. **多层嵌套列表管理（List-based）**：

   * 以树状列表形式组织用户内容，用户可构建个性化知识体系结构

3. **时间线管理（Timeline-based）**：

   * 按时间追踪学习记录、内容收藏与复习安排，适合阶段目标与回顾式学习

> 📦 所有管理均为用户私有，未来将扩展更多组织模型（如推荐引擎、AI 自动归类、个人知识地图等）

## 用户故事（User Stories）

### 用户（User）

* 作为一个学生，我希望可以不登录就浏览所有教学内容，以便快速获取知识点。
* 作为一个学生，我希望可以将喜欢的互动内容保存到我的列表中，以便后续复习。
* 作为一个学生，我希望可以用“标签”对我的内容进行分类，这样我可以有条理地学习。
* 作为一个学生，我希望可以在内容上标注状态：

  * 未学过 (Not Learned/New)
  * 已学过 (Learned/Introduced)
  * 理解中 (In Progress/Actively Learning)
  * 已掌握 (Mastered/Proficient)
  * 需复习 (Needs Review/Scheduled for Review)
  * 模糊/不确定 (Uncertain/Fuzzy)
  * 易错 (Prone to Error/Problematic)
  * 已遗忘 (Forgotten)
  * 已巩固 (Consolidated/Reinforced)
  * 应用中 (Applying/Using)
* 作为一个用户，我希望在页面中有互动和视觉化的展示方式，以便更容易理解抽象知识。
* 作为一个用户，我希望在设置中选择平台一个显示语言。
* 作为一个用户，我希望在设置中选择学习内容的语言（每个创建的内容知识点有一个语言）。
* 作为一个用户，我希望输入自然语言提示生成vue(html, css, js)自动渲染学习内容（代码不显示，只显示渲染
* 作为一个用户，我希望为生成内容打上学科与知识点标签，方便查找。
* 作为一个用户，我希望实时预览内容，确认展示效果后再发布。
* 作为一个用户，我希望看到其他用户的反馈数据和访问热度，这样可以优化内容。
* 作为一个用户，我可以分享学习内容（列表）链接给其他人。

### 教师用户（Admin）
* 作为一个教师，我有普通用户界面的所有功能。
* 作为一个教师，我希望输入vue(html, css, js)代码生成内容。有代码框。

## 安全与隐私

* 用户数据与代码内容全部保存在 Supabase
* 使用 Umami Cloud，通过 API 自主控制数据上报内容，避免追踪滥用
* 所有代码生成过程记录用户 ID 与创建时间，未来可用于审核

---

## 移动端支持

* 所有页面采用响应式布局，兼容手机/平板浏览器
* Vue 渲染区域适配小屏幕，支持 touch 操作

---

## 总结

本 PRD 文件定义了基于 Vue 与 AI 驱动的互动教学内容平台 MVP 范围，明确技术架构与核心交互。

部署架构采用 Supabase（认证+数据库）与 Vercel（前端），通过 Umami Cloud API 实现用户行为追踪，免去后端部署压力，实现了快速上线与维护简便的目标。

未来将进一步支持用户自定义内容生成、收藏、数据统计、付费内容等能力。

如需生成 Wireframe 或 UI Prototyping 可进行后续扩展。
