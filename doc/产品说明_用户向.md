# EduNest 产品说明（面向用户）

本文档面向**最终用户**与**产品/运营**，说明 EduNest 是什么、能做什么、以及用户会接触到的核心概念与流程。技术实现见 `ARCHITECTURE.md`，数据结构见 `DataStructure.md`。

---

## 一、EduNest 是什么

**EduNest** 是一款基于 AI 的智能教育平台，主要提供：

- **AI 生成互动内容**：输入知识点（如「分数运算」「牛顿定律」），由 AI 生成可交互的讲解与练习。
- **AI 老师（AI Guide）**：在任意学习内容页面，可随时向 AI 提问、获得个性化辅导与讲解。
- **内容浏览与收藏**：发现、学习、收藏和整理内容，支持合集与学习记录。
- **多语言**：支持中文、英语、德语、法语等，界面与内容语言可切换。

**适用对象**：教师、学生、家长、教育机构；覆盖从幼儿园到高三的全学段、多学科。

## 二、用户能做什么（功能概览）

| 功能 | 说明 |
|------|------|
| **注册与登录** | 使用邮箱注册/登录；未登录用户可作为访客有限使用（如体验生成、AI 老师）。 |
| **创建与生成内容** | 在「创建」页输入知识点或提示词（可配合上传题目图片），选择学习阶段与类型，由 AI 生成互动式 HTML 内容；生成过程为异步，可查看排队与完成状态。 |
| **浏览与学习内容** | 通过首页、分类或短链接（如 `/c/xxxx`）打开内容，在页面内学习、交互；支持数学公式、图表与交互组件。 |
| **AI 老师（AI Guide）** | 在内容页点击「AI 老师」，在对话框输入问题或需求，AI 会结合当前页面内容作答；支持多轮对话，部分场景支持实时语音。 |
| **产品咨询与问答** | 在帮助/咨询场景可向产品知识库提问（如「怎么用」「价格」「退款」），获得基于知识库的标准回答与推荐内容。 |
| **收藏与合集** | 将喜欢的内容加入「收藏」或自定义「合集」，便于后续复习与分享；合集可设为公开或私有。 |
| **积分与订阅** | 新用户通常有免费积分用于体验 AI 生成；消耗积分生成内容；订阅付费计划可获得更多额度或权益。 |
| **邀请与奖励** | 通过邀请码邀请他人注册，满足条件可获得积分或奖励。 |
| **学习与反馈** | 对内容评分、对 AI 老师回答做「有帮助/无帮助」反馈，用于改进产品（若已开放）。 |

## 三、核心概念（用户视角）

- **内容（Content）**  
  一条由 AI 生成或人工创建的学习单元，包含标题、知识点、完整交互页面（HTML）。每条内容有唯一**短链接**（如 `你的站点/c/abc12345`），便于分享与再次打开。

- **知识点 / 提示词**  
  用户输入的一句话或关键词（如「二次函数顶点」「细胞结构」），用于告诉 AI 要生成哪类讲解或练习。

- **AI 老师 / AI Guide**  
  绑定在「当前正在学习的内容」上的智能助手。你提问时，AI 会结合该页面的主题与上下文回答，而不是泛泛而谈。

- **对话（Conversation）**  
  一次与 AI 老师的多轮问答称为一条对话；可包含多组「用户问 + AI 答」，并可能关联某条内容的短链接。

- **合集（Collection List）**  
  用户创建的「文件夹」或「播单」，用来把多条内容归类（如「八年级数学」「期末复习」）。合集可公开给他人浏览，也可设为私有。

- **收藏（User Collection）**  
  用户把某条内容加入某个合集或默认收藏列表的动作；可附带标签、备注或学习日期（视产品界面而定）。

- **积分（Credits）**  
  平台内用于「兑换」AI 生成次数的虚拟额度。新用户通常获得一定免费积分；生成一条内容会扣除相应积分；邀请他人、订阅等可能增加积分。

- **订阅（Subscription）**  
  用户购买的付费计划（如月付/年付），用于获得更多积分、更高额度或专属功能；通过 Stripe 支付，支持取消与续期管理。

- **访客（Visitor）**  
  未登录用户会有一个匿名访客 ID，用于在未注册情况下有限使用生成或 AI 老师，并做用量统计；登录后与账号关联。

## 四、典型使用流程

### 4.1 新用户：从注册到第一次生成

1. 打开站点 → 注册/登录（或先以访客身份体验）。
2. 进入「创建」或「AI 生成」入口。
3. 输入知识点（例如「分数加减法」），可选学习阶段、类型；有需要可上传题目图片。
4. 提交生成 → 系统排队处理 → 页面上可看到「等待中」「生成中」或「完成」。
5. 生成完成后，自动跳转或从「我的创作」打开内容页，开始学习；可点击「AI 老师」对该页内容提问。

### 4.2 学习与复习

1. 在首页或分类中浏览内容，或通过别人分享的短链接（`/c/xxxx`）打开。
2. 在内容页内阅读、做题、交互。
3. 需要时点击「AI 老师」提问，进行多轮对话。
4. 将有用内容加入收藏或自己的合集，方便以后复习。

### 4.3 订阅与积分

1. 在「积分」或「订阅」页查看当前额度和套餐。
2. 选择月付/年付等计划 → 跳转至 Stripe 支付页完成付款。
3. 支付成功后跳回站点「订阅成功」页，积分或权益自动生效。
4. 可在「订阅管理」中查看续期时间、取消订阅等。

### 4.4 产品咨询（知识库问答）

1. 在帮助页或产品咨询入口输入问题（如「怎么用」「多少钱」「如何退款」）。
2. 系统根据知识库返回回答，并可能推荐相关功能或内容链接。
3. 用户可继续追问，或按推荐去使用对应功能。

## 五、内容与生成状态（用户可见）

- **内容状态**  
  用户创建或打开的内容要么「正常可看」，要么「已删除」（若支持软删除，用户侧可能显示为「内容不存在」）。

- **生成任务状态**  
  用户提交一次「生成」会对应后台一条任务，用户侧通常看到：
  - **等待中（pending）**：在队列中排队。
  - **生成中（processing）**：AI 正在生成与渲染。
  - **完成**：生成成功，可打开内容链接学习。
  - **失败**：生成失败，可能提示重试或联系支持。

若任务长时间停在「生成中」，系统可能会自动将其标记为超时失败，用户可重新发起生成。

## 六、多语言与访问方式

- **界面语言**：用户可在站点内切换界面语言（如中文、英文、德文、法文），部分功能与知识库回答会随语言切换。
- **内容语言**：每条内容有语言属性（如 zh-CN、en-US），生成时可选择；浏览时可按语言筛选。
- **访问方式**：支持桌面浏览器与移动端浏览器；部分能力（如实时语音）可能依赖设备与网络环境。

## 七、与架构、数据的对应关系（供产品/运营参考）

| 用户概念 | 架构/数据对应 |
|----------|----------------|
| 内容 | 后端 `content` 表；`full_html` 存完整页面，`short_id` 对应短链。 |
| 生成任务 | `ai_usage_logs` 表；`status`：pending / processing / completed / failed；`content_id` 关联生成结果。 |
| AI 老师对话 | `ai_conversations` + `ai_messages`；可关联 `content_id` 表示「针对某条内容的对话」。 |
| 知识库问答 | `kb_entries`（FAQ/问答）+ 向量检索；用户提问走 RAG 流程后返回回答与推荐。 |
| 合集与收藏 | `collection_lists`（合集）+ `user_collections`（用户收藏关系）。 |
| 积分 | `user_credits` 表记录变动；展示时汇总为当前余额。 |
| 订阅与支付 | `subscriptions` + `payments`；与 Stripe 同步。 |
| 访客 | `visitor_usage` 等；未登录用户由 `visitor_id` 标识。 |
