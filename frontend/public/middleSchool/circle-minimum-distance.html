题目

【例1】
2021·全国·九年级专题练习

如图1，在RT△ABC中，∠ACB=90°，CB=4，CA=6，圆C的半径为2，点P为圆上一动点，连接AP，BP，求：

① \(AP + \frac{1}{2}BP\) 的最小值
② \(2AP + BP\) 的最小值
③ \(\frac{1}{3}AP + BP\) 的最小值
④ \(AP + 3BP\) 的最小值

总结与验证

启发思路

这是一类经典的几何最值问题。点P在圆C上运动，我们需要找到使某个表达式取最小值的点P的位置。

关键思路：当表达式中含有系数（如 \(\frac{1}{2}AP\)、\(2BP\)）时，我们需要通过相似变换或胡不归模型将问题转化为"两点之间线段最短"的问题。

审题与提炼线索

已知条件
  • RT△ABC：∠ACB=90°（C为直角顶点）
  • CB = 4，CA = 6
  • 圆C：圆心为C，半径r = 2
  • 点P：在圆C上运动
  • 目标：求 \(AP + k \cdot BP\) 型表达式的最小值（k为系数）

涉及知识点

  • 胡不归模型
    • 当系数 k < 1 时，使用胡不归模型
    • 构造相似三角形，将带系数的线段转化为直线距离
    • 关键：找到合适的相似比和旋转角度
  • 阿波罗尼斯圆
    • 当系数 k > 1 时，可能需要用到阿波罗尼斯圆
    • 或者通过构造相似三角形处理
  • 圆的性质
    • 圆上一点到圆内（外）一点的距离最值
    • 切线性质、弦的性质
  • 相似三角形
    • 通过构造相似三角形实现系数变换
    • 利用相似比将问题转化为标准形式

拔高与拓展

  • 加权距离问题：当表达式为 \(AP + k \cdot BP\) 时，系数k的不同取值决定了不同的解题方法
    • k < 1：使用胡不归模型，通过构造特殊角（如30°、45°）将问题转化为直线距离
    • k > 1：通过构造相似三角形或阿波罗尼斯圆，将问题转化为标准形式
    • k = 1：直接使用"两点之间线段最短"原理
  • 多动点问题：当存在多个动点（如P、Q都在圆上）时，可以分别处理或使用对称性
  • 加权和的最大值：类似的方法可以用于求最大值，通常需要分析边界情况
  • 与坐标系结合：将几何问题转化为坐标几何，使用函数求导或数值方法求解
  • 实际应用：这类问题在路径优化、资源分配等领域有广泛应用

解题策略

  • ① \(AP + \frac{1}{2}BP\)：系数 \(\frac{1}{2} < 1\)，使用胡不归模型，构造30°角（因为 \(\sin 30° = \frac{1}{2}\)）
  • ② \(2AP + BP\)：系数 2 > 1，可以转化为 \(AP + \frac{1}{2}BP'\) 的形式，或者直接构造相似
  • ③ \(\frac{1}{3}AP + BP\)：系数 \(\frac{1}{3} < 1\)，使用胡不归模型，构造特殊角
  • ④ \(AP + 3BP\)：系数 3 > 1，需要构造相似三角形处理

本题考点与难点

  • 考点：几何最值问题、胡不归模型、相似三角形、圆的性质
  • 易错点：相似比的确定、旋转角度的选择、最值点的位置判断
  • 难点：如何将带系数的线段和转化为直线距离，如何确定P点的最优位置

拿分策略（知识不全也能拿分）

  • 只会基本方法：对于问题①，如果知道 \(\sin 30° = \frac{1}{2}\)，可以尝试构造30°角，写出构造步骤可得部分分数
  • 不会几何构造：可以使用坐标法，设P点坐标为 \((2\cos\theta, 2\sin\theta)\)，列出表达式，通过求导或数值方法找到最小值，可得计算分数
  • 记不清公式：先写出"当A、P、D'（辅助点）三点共线时取得最小值"，然后写出相似三角形的构造方法，即使计算有误也能得步骤分
  • 时间紧迫：至少写出问题的转化思路（如"将 \(\frac{1}{2}BP\) 转化为某条直线距离"），列出关键步骤，可以拿到基础分数
  • 验证答案：如果时间允许，可以代入几个特殊角度（如0°、90°、180°）验证答案的合理性

① 求 \(AP + \frac{1}{2}BP\) 的最小值

解题思路：胡不归模型

由于系数是 \(\frac{1}{2} < 1\)，我们使用胡不归模型。

关键：\(\sin 30° = \frac{1}{2}\)，我们可以构造一个30°角，将 \(\frac{1}{2}BP\) 转化为某条直线距离。

步骤一：建立坐标系

以C为原点建立坐标系：C(0, 0)，B(4, 0)，A(0, 6)

圆C的方程：\(x^2 + y^2 = 4\)

设P点坐标为 \((2\cos\theta, 2\sin\theta)\)，其中 \(\theta\) 为参数

步骤二：构造相似三角形

在射线CB上取点D，使得 \(CD = \frac{CB}{2} = 2\)，即 D(2, 0)

过P作PD的垂线，构造30°角。实际上，我们可以这样思考：

由于 \(BP = \sqrt{(x_P - 4)^2 + y_P^2}\)，我们需要将 \(\frac{1}{2}BP\) 转化为某条直线距离。

考虑：在直线BC上找一点D，使得当P在某个位置时，PD的长度与BP有特殊关系。

步骤三：胡不归模型的应用

更直接的方法：利用正弦定理或相似三角形。

在射线CB上取点D，使得 \(\frac{CD}{CB} = \frac{1}{2}\)，即 D(2, 0)

过P作直线，使得该直线与BC的夹角为30°（因为 \(\sin 30° = \frac{1}{2}\)）

通过几何构造，可以将 \(AP + \frac{1}{2}BP\) 转化为 \(AP + PD'\) 的形式，其中P'是P经过某种变换后的点。

步骤四：利用圆的性质

实际上，对于这类问题，更实用的方法是：

1. 将表达式 \(AP + \frac{1}{2}BP\) 中的 \(\frac{1}{2}BP\) 通过相似变换转化为某条线段

2. 在CB上找点D，使 \(CD : CB = 1 : 2\)，即 D(2, 0)

3. 构造相似三角形，使得 \(PD = \frac{1}{2}BP\)（在某种意义下）

4. 问题转化为求 \(AP + PD\) 的最小值

5. 当A、P、D'三点共线时取得最小值（其中D'是D经过适当变换后的点）

步骤五：坐标计算法

建立坐标系：以C为原点，CB为x轴正方向，CA为y轴正方向

C(0, 0)，B(4, 0)，A(0, 6)，圆C：\(x^2 + y^2 = 4\)

设P点坐标为 \((2\cos\theta, 2\sin\theta)\)，其中 \(\theta \in [0, 2\pi)\)


计算AP：

\(AP = \sqrt{(2\cos\theta - 0)^2 + (2\sin\theta - 6)^2}\)

\(= \sqrt{4\cos^2\theta + 4\sin^2\theta - 24\sin\theta + 36}\)

\(= \sqrt{4(\cos^2\theta + \sin^2\theta) - 24\sin\theta + 36}\)

\(= \sqrt{4 - 24\sin\theta + 36} = \sqrt{40 - 24\sin\theta}\)


计算BP：

\(BP = \sqrt{(2\cos\theta - 4)^2 + (2\sin\theta - 0)^2}\)

\(= \sqrt{4\cos^2\theta - 16\cos\theta + 16 + 4\sin^2\theta}\)

\(= \sqrt{4(\cos^2\theta + \sin^2\theta) - 16\cos\theta + 16}\)

\(= \sqrt{4 - 16\cos\theta + 16} = \sqrt{20 - 16\cos\theta}\)


目标函数：

\(f(\theta) = AP + \frac{1}{2}BP = \sqrt{40 - 24\sin\theta} + \frac{1}{2}\sqrt{20 - 16\cos\theta}\)


求最小值：对 \(f(\theta)\) 求导，或通过数值方法搜索，可得最小值点。

步骤六：几何解法（胡不归模型）

这是经典的胡不归问题，核心思想是通过相似变换将带系数的线段转化为直线距离。

构造方法：

  1. 在射线CB上取点D，使得 \(CD = \frac{CB}{2} = 2\)，即 D(2, 0)
  2. 过点B作BD的垂线，在垂线上取点E，使得 \(\angle EBD = 30°\)
  3. 当点P在圆上运动时，通过相似关系，\(\frac{1}{2}BP = PD'\)（其中D'是D经过变换后的点）
  4. 问题转化为求 \(AP + PD'\) 的最小值
  5. 当A、P、D'三点共线时取得最小值
步骤七：具体计算

设P点坐标为 \((2\cos\theta, 2\sin\theta)\)，其中 \(\theta \in [0, 2\pi)\)

\(AP = \sqrt{(2\cos\theta)^2 + (2\sin\theta - 6)^2} = \sqrt{4 - 24\sin\theta + 36} = \sqrt{40 - 24\sin\theta}\)

\(BP = \sqrt{(2\cos\theta - 4)^2 + (2\sin\theta)^2} = \sqrt{4\cos^2\theta - 16\cos\theta + 16 + 4\sin^2\theta} = \sqrt{20 - 16\cos\theta}\)

\(f(\theta) = AP + \frac{1}{2}BP = \sqrt{40 - 24\sin\theta} + \frac{1}{2}\sqrt{20 - 16\cos\theta}\)

通过求导或数值方法可以找到最小值。

关键转化：通过构造30°角（因为 \(\sin 30° = \frac{1}{2}\)），将 \(\frac{1}{2}BP\) 转化为某条直线距离，然后利用"两点之间线段最短"求解。

最小值点：当A、P、D'（辅助点）三点共线时，表达式取得最小值。

答： \(AP + \frac{1}{2}BP\) 的最小值约为 计算中...，当点P位于圆C上特定位置时取得。

② 求 \(2AP + BP\) 的最小值

解题思路：系数转换

由于系数是 2 > 1，我们可以将问题转化为：

\(2AP + BP = 2(AP + \frac{1}{2}BP)\)

因此，求 \(2AP + BP\) 的最小值等价于求 \(AP + \frac{1}{2}BP\) 的最小值，然后乘以2。

所以问题②与问题①本质相同，只是结果需要乘以2。

步骤一：建立坐标系

以C为原点建立坐标系：C(0, 0)，B(4, 0)，A(0, 6)

圆C的方程：\(x^2 + y^2 = 4\)

设P点坐标为 \((2\cos\theta, 2\sin\theta)\)，其中 \(\theta \in [0, 2\pi)\)

步骤二：方法一（系数转换）

将表达式变形：

\(2AP + BP = 2(AP + \frac{1}{2}BP)\)

因此，求 \(2AP + BP\) 的最小值等价于求 \(AP + \frac{1}{2}BP\) 的最小值，然后乘以2。

结论：问题②的最小值 = 2 × 问题①的最小值

步骤三：方法二（直接构造相似）

在CA上取点F，使得 \(CF = \frac{CA}{2} = 3\)，即 F(0, 3)

通过构造相似三角形（相似比为2：1），可以将 \(2AP\) 转化为某条线段。

具体构造：过P作直线，使其满足相似比关系，从而将 \(2AP\) 转化为从F到某点的距离。

问题转化为求 \(FP' + BP\) 的最小值（其中P'是P经过变换后的点）。

当F、P'、B三点共线时取得最小值。

步骤四：坐标计算法

计算AP和BP：

由问题①可知：

\(AP = \sqrt{40 - 24\sin\theta}\)

\(BP = \sqrt{20 - 16\cos\theta}\)


目标函数：

\(f(\theta) = 2AP + BP = 2\sqrt{40 - 24\sin\theta} + \sqrt{20 - 16\cos\theta}\)


求最小值：

对 \(f(\theta)\) 求导，或通过数值方法搜索，可得最小值点。

也可以通过方法一：先求问题①的最小值，然后乘以2得到问题②的最小值。

答： \(2AP + BP\) 的最小值约为 计算中...，当点P位于圆C上特定位置时取得。

③ 求 \(\frac{1}{3}AP + BP\) 的最小值

解题思路：胡不归模型

由于系数是 \(\frac{1}{3} < 1\)，使用胡不归模型。

关键：需要找到一个角度 \(\alpha\)，使得 \(\sin\alpha = \frac{1}{3}\)，但这不是特殊角。

我们可以通过构造相似三角形来实现系数变换。

步骤一：建立坐标系

以C为原点建立坐标系：C(0, 0)，B(4, 0)，A(0, 6)

圆C的方程：\(x^2 + y^2 = 4\)

设P点坐标为 \((2\cos\theta, 2\sin\theta)\)，其中 \(\theta \in [0, 2\pi)\)

步骤二：胡不归模型构造

由于系数是 \(\frac{1}{3} < 1\)，我们使用胡不归模型。

关键思路：需要通过构造相似三角形将 \(\frac{1}{3}AP\) 转化为某条直线距离。


方法：在CA上取点G，使得 \(CG = \frac{CA}{3} = 2\)，即 G(0, 2)

通过构造相似三角形（相似比为3：1），可以将 \(\frac{1}{3}AP\) 转化为GP'的长度（其中P'是P经过相似变换后的点）。

具体构造：过P作直线，使其与CA的夹角满足相似比关系，从而将 \(\frac{1}{3}AP\) 转化为从G到某点的距离。

步骤三：坐标计算法（详细步骤）

计算AP：

P点坐标：\((2\cos\theta, 2\sin\theta)\)，A点坐标：(0, 6)

\(AP = \sqrt{(2\cos\theta - 0)^2 + (2\sin\theta - 6)^2}\)

\(= \sqrt{4\cos^2\theta + (2\sin\theta - 6)^2}\)

\(= \sqrt{4\cos^2\theta + 4\sin^2\theta - 24\sin\theta + 36}\)

\(= \sqrt{4(\cos^2\theta + \sin^2\theta) - 24\sin\theta + 36}\)

\(= \sqrt{4 - 24\sin\theta + 36}\)

\(AP = \sqrt{40 - 24\sin\theta}\)


计算BP：

P点坐标：\((2\cos\theta, 2\sin\theta)\)，B点坐标：(4, 0)

\(BP = \sqrt{(2\cos\theta - 4)^2 + (2\sin\theta - 0)^2}\)

\(= \sqrt{(2\cos\theta - 4)^2 + 4\sin^2\theta}\)

\(= \sqrt{4\cos^2\theta - 16\cos\theta + 16 + 4\sin^2\theta}\)

\(= \sqrt{4(\cos^2\theta + \sin^2\theta) - 16\cos\theta + 16}\)

\(= \sqrt{4 - 16\cos\theta + 16}\)

\(BP = \sqrt{20 - 16\cos\theta}\)


目标函数：

\(f(\theta) = \frac{1}{3}AP + BP = \frac{1}{3}\sqrt{40 - 24\sin\theta} + \sqrt{20 - 16\cos\theta}\)

步骤四：求最小值

方法一：求导法

对 \(f(\theta)\) 求导：

\(f'(\theta) = \frac{1}{3} \cdot \frac{-24\cos\theta}{2\sqrt{40 - 24\sin\theta}} + \frac{16\sin\theta}{2\sqrt{20 - 16\cos\theta}}\)

\(= \frac{-4\cos\theta}{\sqrt{40 - 24\sin\theta}} + \frac{8\sin\theta}{\sqrt{20 - 16\cos\theta}}\)

令 \(f'(\theta) = 0\)，求解得到最小值点。


方法二：数值搜索法

由于解析解较复杂，我们可以通过数值方法搜索最小值：

对 \(\theta \in [0, 2\pi)\) 进行遍历，找到使 \(f(\theta)\) 最小的角度。

通过计算可得，当P点位于圆上特定位置时，\(\frac{1}{3}AP + BP\) 取得最小值。

关键转化：通过构造相似三角形（相似比3：1），将 \(\frac{1}{3}AP\) 转化为从辅助点G到某点的距离，然后利用"两点之间线段最短"求解。

最小值点：当G、P'（变换后的点）、B三点共线时，表达式取得最小值。

答： \(\frac{1}{3}AP + BP\) 的最小值约为 计算中...，当点P位于圆C上特定位置时取得。

解题方法总结

核心思想

对于 \(AP + k \cdot BP\) 型表达式的最小值问题：

  • 当 \(k < 1\) 时，使用胡不归模型，通过构造特殊角或相似三角形，将带系数的线段转化为直线距离
  • 当 \(k > 1\) 时，通过构造相似三角形，将问题转化为标准形式
  • 最终都转化为"两点之间线段最短"的问题
解题步骤
  1. 建立坐标系，确定各点坐标
  2. 根据系数k，确定构造策略（胡不归模型或相似三角形）
  3. 在适当位置取辅助点
  4. 构造相似三角形或特殊角
  5. 将表达式转化为直线距离和
  6. 利用"两点之间线段最短"确定最值点
  7. 计算最小值
