亮点问题全解析：图形与演示一步到位

题目选自几何综合练习第 24 题，我们将保持“亮点”的定义，完全站在初中生能掌握的知识点上，利用图像、表格与动画解释三问。

原题回顾

约定：在平面直角坐标系 \(xOy\) 中，两点 \(M(x_1,y_1)\)、\(N(x_2,y_2)\) 不重合。若 \(x_1 + y_1 = x_2 + y_2\)，称点 \(N\) 为点 \(M\) 的“亮点”。

(1) 已知 \(N\) 是点 \(M(3,2)\) 的亮点，且 \(N\) 在直线 \(y = x + 2\) 上，求点 \(N\) 的坐标。

(2) 已知点 \(N(x_2,y_2)\) 为点 \(M(x_1,y_1)\) 的亮点，且满足 \[ x_1^2 y_1^2 + x_2^2 y_2^2 + 4(x_1 y_1 + x_2 y_2) = -8,\quad S_{\triangle MON} = \frac{3}{2}, \] 求直线 \(MN\) 的解析式。

(3) 把抛物线 \(y = -x^2 + 2x + 3\) 在 \(x \leq m\)（其中 \(m < 3\)）的部分记作 \(W_1\)，再把它沿直线 \(x = m\) 翻折后得到的图像记作 \(W_2\)。已知 \(W_1 \cup W_2\) 上恰好出现点 \(M(0,m)\) 的两个亮点。令 \[ P = -m^2 + 2tm + t, \] 若对所有满足条件的 \(m\)，都有 \(P \le t+1\)，求实数 \(t\) 的取值范围。

解题导航

启发思路

把“亮点”想成一束光：同一束光上所有点都有相同的“横坐标 + 纵坐标”。因此我们可以把亮点放在直线 \(x+y=\text{常数}\) 上找。

审题与提炼线索
  • 所有小题都离不开：亮点 ⇒ x+y 相等。
  • 第一问：已知直线，再叠加亮点条件。
  • 第二问：亮点对称 + 三角形面积，考察坐标运算。
  • 第三问：二次函数翻折，亮点来自镜像交点，最后串联到不等式。
涉及知识点（树状图）
  • 亮点直线：\(x+y=s\)；求交点——一次函数联立。
  • 面积公式：\(S_{\triangle AOB}=\tfrac12|x_1y_2-x_2y_1|\)，来源于平行四边形面积。
  • 镜面反射：关于直线 \(x=m\) 的翻折，坐标变换 \(x' = 2m - x\)。
  • 二次函数最值：\((m-t)^2\) 最小值 + 区间位置 → 处理不等式。
拿分策略
  • 亮点题不会迷失：先写出 \(x+y=s\)，再结合条件联立。
  • 面积题怕代数：记住“两个点的三角形面积”公式，直接代坐标。
  • 翻折题怕运算：先写“新横坐标 = 2m - 旧横坐标”，其余保持不动。
  • 不等式看不懂：把式子改写成“一个平方 ≥ 常数”，用最小值判断。

(1) 在直线 y = x + 2 上找亮点

解题步骤
  1. 写出亮点等式：\(x + y = 3 + 2 = 5\)。
  2. 利用直线 \(y = x + 2\) 把 \(y\) 表示成 \(x\)。
  3. 代入得到方程：\(x + (x+2) = 5\)，求出 \(x\)，再回代求 \(y\)。
\[ \begin{aligned} &x + (x+2) = 5 \Rightarrow 2x = 3 \Rightarrow x = \frac{3}{2},\\ &y = x + 2 = \frac{7}{2}. \end{aligned} \]
提示：“亮点线”与“给定直线”交点即答案，一定要先写出亮点方程。
点 \(N\left(\dfrac{3}{2},\dfrac{7}{2}\right)\)。

蓝色直线是 \(y = x + 2\)，红点为 \(M(3,2)\)，绿色点为求出的亮点 \(N\)。

(2) 面积条件下的两组亮点

拆分条件
  1. 亮点关系：\(x_1 + y_1 = x_2 + y_2 = s\)。
  2. 代入等式可化为：\(x_1 y_1 = x_2 y_2 = -2\)。
  3. 面积条件：\(|x_1 y_2 - x_2 y_1| = 3\)（利用面积公式）。

①、② 两条说明 \((x_1, y_1)\) 与 \((x_2, y_2)\) 是同一二次方程的两根互换。

两种可能

由根与系数关系得到 \(s = x_1 + y_1\) 可能取 \(1\) 或 \(-1\)。于是有两种成对坐标：

  • \(M(2, -1)\)，\(N(-1, 2)\)，直线 \(MN: y = -x + 1\)。
  • \(M(1, -2)\)，\(N(-2, 1)\)，直线 \(MN: y = -x - 1\)。
解析式： \(y = -x + 1\)；对应点 \(M(2,-1)\)，\(N(-1,2)\)。
解析式： \(y = -x - 1\)；对应点 \(M(1,-2)\)，\(N(-2,1)\)。
说明：面积条件只决定“差值的绝对值=3”，所以会出现左右互换的两种情况。

紫色三角形表示 \(\triangle MON\)，绿色/红色点分别为 \(M\)、\(N\)。可切换上方选项查看两种情况。

(3) 二次函数翻折与不等式

第一步：找到两个亮点

对于曲线 \(W_1\)、\(W_2\)，亮点同时满足 \(x + y = m\)。计算结果：

第二步：分析表达式 \(P = -m^2 + 2tm + t\)

我们已知 \(m\) 的活动区间是 \((-1, 3)\)。要让 \(P \le t + 1\) 对所有这样的 \(m\) 都成立，可以改写为：

\[ -m^2 + 2tm + t \le t + 1 \Longleftrightarrow (m - t)^2 \ge t^2 - 1. \]

左边是一个平方，最小值发生在“t 到区间 (-1,3) 的距离”上。观察得：

  • 若 \(t \in [-1,1]\)，可取 \(m = t\)，左侧最小值为 0，必然满足不等式；
  • 若 \(t < -1\) 或 \(t > 1\)，即使取最优的 \(m\)，左侧最小值也小于右侧需要的数值，条件不再成立。

趣味总结

亮点线像一条隐形的“跑道”，所有亮点都在同一条跑道上。一次函数画跑道，面积公式测“跑道+终点”形成的三角形，而抛物线翻折是在做“镜子实验”。

结果速览
  • (1) \(N\left(\dfrac{3}{2}, \dfrac{7}{2}\right)\)。
  • (2) 直线 \(y = -x + 1\) 或 \(y = -x - 1\)，对应两组亮点交换。
  • (3) \(m \in (-1,3)\) 时才会出现两个亮点，进而限定 \(t \in [-1,1]\)。
就地验证
  • 在 (1)(2) 的画布中拖动或切换选项，检验亮点是否都在同一条 \(x+y=s\) 线上。
  • 在 (3) 里改变 \(m\)、播放翻折动画，观察镜面关系与不等式参数的变化。
