2024·上海普陀·高三校考期末 - 球面切平面问题

题目

对于一个三维空间，如果一个平面与一个球只有一个交点，则称这个平面是这个球的切平面。


已知在空间直角坐标系 \(O-xyz\) 中，球 \(O\) 的半径为 1，记平面 \(xOy\)、平面 \(zOx\)、平面 \(yOz\) 分别为 \(\alpha\)、\(\beta\)、\(\gamma\)。


(1) 若棱长为 \(a\) 的正方体、棱长为 \(b\) 的正四面体的内切球均为球 \(O\)，求 \(\frac{a}{b}\) 的值；


(2) 若球 \(O\) 在 \(\left(\frac{1}{\sqrt{6}}, \frac{1}{\sqrt{3}}, \frac{1}{\sqrt{2}}\right)\) 处有一切平面为 \(\lambda_0\)，求 \(\lambda_0\) 与 \(\alpha\) 的交线方程，并写出它的一个法向量；


(3) 如果在球面上任意一点作切平面 \(\lambda\)，记 \(\lambda\) 与 \(\alpha\)、\(\beta\)、\(\gamma\) 的交线分别为 \(m\)、\(n\)、\(p\)，求 \(O\) 到 \(m\)、\(n\)、\(p\) 距离乘积的最小值。

(1) 正方体和正四面体内切球

分析：
已知球 \(O\) 的半径为 1，分别计算正方体和正四面体的内切球半径与棱长的关系。
正方体内切球：

对于棱长为 \(a\) 的正方体：

内切球半径 = \(\frac{a}{2}\)

根据题意：\(\frac{a}{2} = 1\)

所以：\(a = 2\)

正四面体内切球：

对于棱长为 \(b\) 的正四面体：

内切球半径 \(r = \frac{b\sqrt{6}}{12}\)


证明：正四面体的体积 \(V = \frac{b^3\sqrt{2}}{12}\)

表面积 \(S = b^2\sqrt{3}\)

内切球半径 \(r = \frac{3V}{S} = \frac{3 \cdot \frac{b^3\sqrt{2}}{12}}{b^2\sqrt{3}} = \frac{b\sqrt{2}}{4\sqrt{3}} = \frac{b\sqrt{6}}{12}\)


根据题意：\(\frac{b\sqrt{6}}{12} = 1\)

所以：\(b = \frac{12}{\sqrt{6}} = 2\sqrt{6}\)

求解比值：
\[\frac{a}{b} = \frac{2}{2\sqrt{6}} = \frac{1}{\sqrt{6}} = \frac{\sqrt{6}}{6}\]
答：(1) \(\frac{a}{b} = \frac{\sqrt{6}}{6}\)

(2) 切平面方程与交线

已知：

球 \(O\)：\(x^2 + y^2 + z^2 = 1\)

切点：\(\left(\frac{1}{\sqrt{6}}, \frac{1}{\sqrt{3}}, \frac{1}{\sqrt{2}}\right)\)

坐标平面 \(\alpha\)：\(z = 0\)（即平面 \(xOy\)）

切平面方程：

对于球面 \(x^2 + y^2 + z^2 = 1\)，在点 \((x_0, y_0, z_0)\) 处的切平面方程为：

\[x_0x + y_0y + z_0z = 1\]

代入切点坐标：

\[\frac{1}{\sqrt{6}}x + \frac{1}{\sqrt{3}}y + \frac{1}{\sqrt{2}}z = 1\]

这就是切平面 \(\lambda_0\) 的方程。

求 \(\lambda_0\) 与 \(\alpha\) 的交线：

将 \(\alpha\)：\(z = 0\) 代入切平面方程：

\[\frac{1}{\sqrt{6}}x + \frac{1}{\sqrt{3}}y = 1\]

等式两边同时乘以 \(\sqrt{6}\)：

\[x + \sqrt{2}y = \sqrt{6}\]

整理得：

\[x + \sqrt{2}y - \sqrt{6} = 0 \quad (z = 0)\]
法向量：

交线在平面 \(\alpha\)（即 \(z = 0\)）上，一个法向量为：

\[\vec{n} = (1, \sqrt{2}, 0)\]
答：(2) 交线方程为 \(x + \sqrt{2}y - \sqrt{6} = 0 \quad (z = 0)\)，一个法向量为 \(\vec{n} = (1, \sqrt{2}, 0)\)

(3) 距离乘积的最小值

分析：

设球面上任意一点为 \(P(x_0, y_0, z_0)\)，满足 \(x_0^2 + y_0^2 + z_0^2 = 1\)。

该点处的切平面 \(\lambda\) 方程为：

\[x_0x + y_0y + z_0z = 1\]
求交线方程：

交线 \(m\)（\(\lambda \cap \alpha\)）：

将 \(z = 0\) 代入得：\(x_0x + y_0y = 1\)

点 \(O\) 到直线 \(m\) 的距离：\(d_1 = \frac{|x_0 \cdot 0 + y_0 \cdot 0 - 1|}{\sqrt{x_0^2 + y_0^2}} = \frac{1}{\sqrt{x_0^2 + y_0^2}}\)


交线 \(n\)（\(\lambda \cap \beta\)）：

将 \(y = 0\) 代入得：\(x_0x + z_0z = 1\)

点 \(O\) 到直线 \(n\) 的距离：\(d_2 = \frac{1}{\sqrt{x_0^2 + z_0^2}}\)


交线 \(p\)（\(\lambda \cap \gamma\)）：

将 \(x = 0\) 代入得：\(y_0y + z_0z = 1\)

点 \(O\) 到直线 \(p\) 的距离：\(d_3 = \frac{1}{\sqrt{y_0^2 + z_0^2}}\)

距离乘积：
\[P = d_1 \cdot d_2 \cdot d_3 = \frac{1}{\sqrt{x_0^2 + y_0^2}} \cdot \frac{1}{\sqrt{x_0^2 + z_0^2}} \cdot \frac{1}{\sqrt{y_0^2 + z_0^2}}\]
\[\frac{1}{P^2} = (x_0^2 + y_0^2)(x_0^2 + z_0^2)(y_0^2 + z_0^2)\]
求最小值：

因为 \(x_0^2 + y_0^2 + z_0^2 = 1\)，所以：

\[(x_0^2 + y_0^2)(x_0^2 + z_0^2)(y_0^2 + z_0^2)\] \[= (1 - z_0^2)(1 - y_0^2)(1 - x_0^2)\] \[= (1 - x_0^2)(1 - y_0^2)(1 - z_0^2)\]

由对称性及均值不等式，当 \(x_0^2 = y_0^2 = z_0^2 = \frac{1}{3}\) 时，\((1 - x_0^2)(1 - y_0^2)(1 - z_0^2)\) 取得最大值，即 \(\frac{1}{P^2}\) 最大，因此 \(P\) 最小。


此时：

\[\frac{1}{P^2} = \left(1 - \frac{1}{3}\right)^3 = \left(\frac{2}{3}\right)^3 = \frac{8}{27}\]

所以：\(P^2 = \frac{27}{8}\)

因此：\(P = \frac{3\sqrt{6}}{4}\)

答：(3) 距离乘积的最小值为 \(\frac{3\sqrt{6}}{4}\)
