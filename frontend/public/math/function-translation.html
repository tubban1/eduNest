函数图像平移问题

题目

7. 将函数\(f(x)\)的图象按向量\(\vec{a} = (m, n)\)平移指的是：当\(m > 0\)时，\(f(x)\)图形向右平移\(m\)个单位；当\(m < 0\)时，\(f(x)\)图形向左平移\(|m|\)个单位；当\(n > 0\)时，\(f(x)\)图形向上平移\(n\)个单位；当\(n < 0\)时，\(f(x)\)图形向下平移\(|n|\)个单位。


已知\(f(x) = 2\sin(2x)\)，将\(f(x)\)的图象按\(\vec{a} = \left(-\frac{\pi}{3}, 1\right)\)平移得到函数\(g(x)\)的图象。


(1) 求\(g(x)\)的解析式；


(2) 若函数\(g(x)\)在区间\([a, b]\)上至少含30个零点，在所有满足上述条件的\([a, b]\)中，求\(b - a\)的最小值；


(3) 对任意的\(x \in \left[-\frac{\pi}{6}, \frac{\pi}{12}\right]\)，不等式\(g^2(x) - mg(x) - 1 \leq 0\)恒成立，求实数\(m\)的取值范围。

解答

(1) 求\(g(x)\)的解析式

分析：

函数\(f(x) = 2\sin(2x)\)的图像按向量\(\vec{a} = \left(-\frac{\pi}{3}, 1\right)\)平移。

根据题意：

  • \(m = -\frac{\pi}{3} < 0\)，所以向左平移\(\frac{\pi}{3}\)个单位
  • \(n = 1 > 0\)，所以向上平移\(1\)个单位
解：

将函数图像向左平移\(\frac{\pi}{3}\)个单位，函数解析式变为：

\[f_1(x) = f\left(x + \frac{\pi}{3}\right) = 2\sin\left[2\left(x + \frac{\pi}{3}\right)\right] = 2\sin\left(2x + \frac{2\pi}{3}\right)\]

再将函数图像向上平移\(1\)个单位，函数解析式变为：

\[g(x) = f_1(x) + 1 = 2\sin\left(2x + \frac{2\pi}{3}\right) + 1\]
函数图像对比：

下图展示了原函数\(f(x) = 2\sin(2x)\)和变换后的函数\(g(x) = 2\sin\left(2x + \frac{2\pi}{3}\right) + 1\)的图像：

图1：原函数\(f(x)\)和平移后的函数\(g(x)\)的图像对比

答：(1) \(g(x) = 2\sin\left(2x + \frac{2\pi}{3}\right) + 1\)

(2) 求区间长度的最小值

分析：

函数\(g(x) = 2\sin\left(2x + \frac{2\pi}{3}\right) + 1\)在区间\([a, b]\)上至少含30个零点。

首先需要求出\(g(x) = 0\)的解，即：

\[2\sin\left(2x + \frac{2\pi}{3}\right) + 1 = 0\] \[\sin\left(2x + \frac{2\pi}{3}\right) = -\frac{1}{2}\]
解：

函数\(g(x) = 2\sin\left(2x + \frac{2\pi}{3}\right) + 1\)的最小正周期为：

\[T = \frac{2\pi}{2} = \pi\]

由\(\sin\left(2x + \frac{2\pi}{3}\right) = -\frac{1}{2}\)，得：

\[2x + \frac{2\pi}{3} = 2k\pi + \frac{7\pi}{6} \quad \text{或} \quad 2x + \frac{2\pi}{3} = 2k\pi + \frac{11\pi}{6} \quad (k \in Z)\]

解第一个方程：

\[2x = 2k\pi + \frac{7\pi}{6} - \frac{2\pi}{3} = 2k\pi + \frac{7\pi - 4\pi}{6} = 2k\pi + \frac{3\pi}{6} = 2k\pi + \frac{\pi}{2}\] \[x = k\pi + \frac{\pi}{4}\]

解第二个方程：

\[2x = 2k\pi + \frac{11\pi}{6} - \frac{2\pi}{3} = 2k\pi + \frac{11\pi - 4\pi}{6} = 2k\pi + \frac{7\pi}{6}\] \[x = k\pi + \frac{7\pi}{12}\]

所以\(g(x)\)的零点为：

\[x = k\pi + \frac{\pi}{4} \quad \text{或} \quad x = k\pi + \frac{7\pi}{12} \quad (k \in Z)\]

计算相邻零点间距：

当\(k\)相同时，\(x = k\pi + \frac{\pi}{4}\)和\(x = k\pi + \frac{7\pi}{12}\)之间的距离为：

\[\left(k\pi + \frac{7\pi}{12}\right) - \left(k\pi + \frac{\pi}{4}\right) = \frac{7\pi}{12} - \frac{3\pi}{12} = \frac{4\pi}{12} = \frac{\pi}{3}\]

当\(k\)相邻时（例如\(k\)和\(k+1\)），间距为\(\pi\)，但这是两个周期之间的间距。

所以相邻零点最小间距为\(\frac{\pi}{3}\)。


要使\(b - a\)最小，且区间\([a, b]\)包含至少30个零点，则\(a\)和\(b\)都必须是零点。


设\(a\)是某个零点。由于函数周期为\(\pi\)，在每个周期内有两个零点，且相邻零点最小间距为\(\frac{\pi}{3}\)。


在区间\([a, a + 14\pi]\)内：

由于周期为\(\pi\)，\(14\pi\)包含\(14\)个周期，每个周期内有\(2\)个零点，所以有\(14 \times 2 = 28\)个零点。

如果包含端点\(a\)（也是一个零点），则区间\([a, a + 14\pi]\)内共有\(28 + 1 = 29\)个零点。


要包含至少30个零点，需要在区间\((a + 14\pi, b]\)内至少还有1个零点。

由于相邻零点最小间距为\(\frac{\pi}{3}\)，所以：

\[b - (a + 14\pi) \geq \frac{\pi}{3}\]

因此：

\[b - a \geq 14\pi + \frac{\pi}{3} = \frac{42\pi + \pi}{3} = \frac{43\pi}{3}\]

当等号成立时，\(b - a\)取得最小值\(\frac{43\pi}{3}\)。

下图展示了函数\(g(x)\)的零点分布：

图2：函数\(g(x)\)的零点分布（红色点表示零点）

答：(2) \(b - a\)的最小值为\(\frac{43\pi}{3}\)

(3) 求\(m\)的取值范围

分析：

对任意的\(x \in \left[-\frac{\pi}{6}, \frac{\pi}{12}\right]\)，不等式\(g^2(x) - mg(x) - 1 \leq 0\)恒成立。

即：对任意的\(x \in \left[-\frac{\pi}{6}, \frac{\pi}{12}\right]\)，有

\[g^2(x) - mg(x) - 1 \leq 0\]

令\(t = g(x)\)，则不等式变为：

\[t^2 - mt - 1 \leq 0\]

这是一个关于\(t\)的二次不等式。

第一步：求\(g(x)\)在区间\(\left[-\frac{\pi}{6}, \frac{\pi}{12}\right]\)上的取值范围

由\(x \in \left[-\frac{\pi}{6}, \frac{\pi}{12}\right]\)，得：

\[2x + \frac{2\pi}{3} \in \left[2 \times \left(-\frac{\pi}{6}\right) + \frac{2\pi}{3}, 2 \times \frac{\pi}{12} + \frac{2\pi}{3}\right]\] \[= \left[-\frac{\pi}{3} + \frac{2\pi}{3}, \frac{\pi}{6} + \frac{2\pi}{3}\right] = \left[\frac{\pi}{3}, \frac{\pi}{6} + \frac{4\pi}{6}\right] = \left[\frac{\pi}{3}, \frac{5\pi}{6}\right]\]

函数\(y = \sin x\)在\(\left[\frac{\pi}{3}, \frac{\pi}{2}\right]\)上单调递增，在\(\left(\frac{\pi}{2}, \frac{5\pi}{6}\right]\)上单调递减。


计算端点值：

\[\sin\left(\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}\] \[\sin\left(\frac{\pi}{2}\right) = 1\] \[\sin\left(\frac{5\pi}{6}\right) = \sin\left(\pi - \frac{\pi}{6}\right) = \sin\left(\frac{\pi}{6}\right) = \frac{1}{2}\]

所以：

\[\sin\left(2x + \frac{2\pi}{3}\right) \in \left[\min\left\{\sin\left(\frac{\pi}{3}\right), \sin\left(\frac{5\pi}{6}\right)\right\}, \sin\left(\frac{\pi}{2}\right)\right] = \left[\frac{1}{2}, 1\right]\]

因此：

\[g(x) = 2\sin\left(2x + \frac{2\pi}{3}\right) + 1 \in [2 \times \frac{1}{2} + 1, 2 \times 1 + 1] = [2, 3]\]

令\(t = g(x)\)，则\(t \in [2, 3]\)。

第二步：分析二次不等式\(t^2 - mt - 1 \leq 0\)

设\(\varphi(t) = t^2 - mt - 1\)。

对任意的\(x \in \left[-\frac{\pi}{6}, \frac{\pi}{12}\right]\)，不等式\(g^2(x) - mg(x) - 1 \leq 0\)恒成立，

即对任意的\(t \in [2, 3]\)，不等式\(\varphi(t) = t^2 - mt - 1 \leq 0\)恒成立。


由于\(\varphi(t)\)是关于\(t\)的开口向上的二次函数，要使\(\varphi(t) \leq 0\)在\([2, 3]\)上恒成立，

只需保证区间端点处的值都\(\leq 0\)即可，即：

\[\varphi(2) = 2^2 - 2m - 1 = 4 - 2m - 1 = 3 - 2m \leq 0\] \[\varphi(3) = 3^2 - 3m - 1 = 9 - 3m - 1 = 8 - 3m \leq 0\]

由\(3 - 2m \leq 0\)，得\(m \geq \frac{3}{2}\)；

由\(8 - 3m \leq 0\)，得\(m \geq \frac{8}{3}\)。


因此：

\[m \geq \frac{8}{3}\]

图3：\(g(x)\)在区间\(\left[-\frac{\pi}{6}, \frac{\pi}{12}\right]\)上的图像及取值范围

答：(3) 实数\(m\)的取值范围为：\(\left[\frac{8}{3}, +\infty\right)\)
