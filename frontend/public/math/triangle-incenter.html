用圆规画三角形的内切圆

📐 题目

题目
几何作图 - 用圆规和直尺画内切圆

🎯 任务：有一个三角形 \(ABC\)，我们要用圆规画一个圆，让这个圆能够"紧贴"三角形的三条边，就像一个小球被三条边"夹住"一样！


📋 步骤：

  1. 第一步：用直尺画出三角形的三条角平分线（把每个角分成两半的线）
  2. 第二步：找到三条角平分线的交点，这个点叫做内心（用字母 \(I\) 表示）
  3. 第三步：用圆规以内心 \(I\) 为圆心，画一个圆，让这个圆刚好碰到三角形的三条边
  4. 第四步：检查一下，这个圆是不是真的和三条边都"贴"在一起了？

💡 小提示：内心到三角形三条边的距离是相等的，这个距离就是我们要画的圆的半径！

🎨 想象一下

在一个三角形里面，有一个圆能够"紧贴"三条边，就像一个小球被三条边"夹住"一样！这个圆的圆心叫做内心，它是三条角平分线的交点。

💭 什么是角平分线？就是把一个角分成两个一样大的角的线，就像把一块蛋糕平均切成两半！

🔍 我们要做什么？

📝 任务清单
  • 🎯 找出三角形的内心（三条角平分线的交点）
  • 📏 测量内心到边的距离（这就是圆的半径）
  • 🔄 用圆规以内心为圆心画圆
  • ✅ 检查圆是否和三条边都"贴"在一起

📚 需要知道的知识

  • 📐 角平分线
    • 把一个角分成两个一样大的角的线
    • 角平分线上的点到角的两边距离一样远
  • 🎯 内心
    • 三条角平分线的交点
    • 内心到三条边的距离都一样远
  • ⭕ 内切圆
    • 圆心在内心
    • 半径 = 内心到边的距离
    • 和三条边都"贴"在一起

🛠️ 需要什么工具？

  • 🔄 圆规：用来画弧和画圆（这是最重要的工具！）
  • 📏 直尺：用来连接点和画直线
  • ✏️ 铅笔：用来标记点和画线

💡 圆规的两个作用：

  1. 画弧，帮助我们找到角平分线上的点
  2. 以内心为圆心画内切圆

📐 什么是角平分线？

角平分线：把一个角分成两个一样大的角的线，就像把一块蛋糕平均切成两半！

🎯 特点：角平分线上的点到角的两边距离一样远。

🎯 什么是内心？

内心的定义

三角形的三条角平分线会交于一点，这个点叫做内心，用字母 \(I\) 表示。

💡 为什么叫"内心"？因为它在这个三角形的"里面"（内部）！

✨ 内心的神奇性质

最重要的性质：内心到三角形三条边的距离完全一样！

📏 这个距离就是我们用圆规画圆时的半径！

⭕ 什么是内切圆？

内切圆：在三角形里面，和三条边都"贴"在一起的圆。

  • 🎯 圆心：三角形的内心 \(I\)
  • 📏 半径：内心到任意一边的距离（三条边都一样！）
  • 📍 切点：圆和边"贴"在一起的那个点

🔄 圆规的两个重要作用

作用一：用圆规画角平分线
  1. 📌 把圆规的针尖放在角的顶点上
  2. 📏 调整圆规的开口，画一个弧，与角的两边相交
  3. 🔄 保持圆规开口不变，以两个交点为圆心画两个弧
  4. 📏 用直尺连接顶点和两个弧的交点，就是角平分线
作用二：用圆规画内切圆
  1. 📌 把圆规的针尖放在内心 \(I\) 上（这是圆心）
  2. 📏 调整圆规的开口，让两脚之间的距离等于半径 \(r\)
  3. 🔄 转动圆规，画出一个完整的圆
  4. ✅ 检查一下，这个圆是不是刚好碰到三条边？

📐 步骤一：找出三角形的内心 \(I\)

🔄 用圆规和直尺画角平分线

第一步：以角的顶点为圆心画弧

把圆规的针尖放在角的顶点（比如顶点 \(A\)），调整圆规的开口，画一个弧，让这个弧和角的两边都相交。这样我们就得到了两个交点。

第二步：以两个交点为圆心画弧

保持圆规的开口不变，分别以刚才得到的两个交点为圆心，画两个弧。这两个弧会在角内部相交于一点。

第三步：连接顶点和交点

用直尺连接角的顶点和刚才找到的交点，这条线就是角平分线！

第四步：重复以上步骤

用同样的方法画出另外两个角的角平分线。

第五步：找交点

三条角平分线会交于一点，这个点就是内心 \(I\)！

💡 小技巧

如果三条线没有交于一点，可能是画得不够准确。多练习几次就会画得更准确了！

✅ 找到了！内心 \(I\) 就是三条角平分线的交点。在下面的动画中，你可以看到如何用圆规一步一步画出角平分线，然后找到它们的交点（内心）！

🔄 步骤二：用圆规画内切圆

📏 第一步：测量半径

用直尺测量从内心 \(I\) 到任意一条边的距离，这个距离就是我们要画的圆的半径！

💡 小秘密：因为内心到三条边的距离都一样，所以测量哪条边都可以！

🔄 第二步：调整圆规

这是圆规最重要的作用！

  1. 📌 把圆规的针尖（固定脚）放在内心 \(I\) 上
  2. 📏 把圆规的铅笔脚调整到刚才测量的距离（半径）
  3. ✅ 检查一下，圆规两脚之间的距离是不是刚好等于半径？
⭕ 第三步：转动圆规画圆

现在可以开始画圆了！

  1. 🔄 保持圆规的针尖在内心 \(I\) 上不动
  2. ✏️ 慢慢转动圆规，让铅笔脚画出一个完整的圆
  3. 👀 仔细观察，这个圆是不是刚好"贴"到三条边？

🎉 完成了！这就是三角形的内切圆！

📏 步骤三：计算内切圆的半径

💡 简单的方法

内切圆的半径可以用一个简单的公式计算：

\[r = \frac{\text{三角形的面积}}{\text{半周长}}\]

📐 半周长就是三条边的长度加起来，再除以2：

\[p = \frac{a + b + c}{2}\]

其中 \(a\)、\(b\)、\(c\) 是三角形的三条边的长度。

📊 计算步骤

第一步：测量三角形的三条边

  • 边 \(AB\) 的长度 = \(c\)
  • 边 \(BC\) 的长度 = \(a\)
  • 边 \(CA\) 的长度 = \(b\)

第二步：计算半周长

\[p = \frac{a + b + c}{2}\]

第三步：计算面积（可以用底×高÷2的方法）

第四步：计算半径

\[r = \frac{S}{p}\]
🔄 用圆规测量

除了用公式计算，我们还可以：

  1. 📏 用直尺从内心 \(I\) 画一条垂线到任意一条边
  2. 📐 测量这条垂线的长度，这就是半径 \(r\)
  3. 🔄 用圆规的两脚量出这个距离，调整圆规的开口

✅ 步骤四：检查圆是否和三条边都"贴"在一起

🔍 怎么检查？

我们要检查从内心 \(I\) 到三条边的距离是不是都一样：

  1. 📏 测量从 \(I\) 到边 \(AB\) 的距离
  2. 📏 测量从 \(I\) 到边 \(BC\) 的距离
  3. 📏 测量从 \(I\) 到边 \(CA\) 的距离
  4. ✅ 如果三个距离都一样，说明圆和三条边都"贴"在一起了！
💡 为什么距离一样？

因为内心在角平分线上！

角平分线有一个神奇的性质：角平分线上的点到角的两边距离一样远！

📐 内心 \(I\) 在角 \(A\) 的平分线上，所以：

\(I\) 到边 \(AB\) 的距离 = \(I\) 到边 \(AC\) 的距离

📐 内心 \(I\) 也在角 \(B\) 的平分线上，所以：

\(I\) 到边 \(AB\) 的距离 = \(I\) 到边 \(BC\) 的距离

🎉 所以：\(I\) 到三条边的距离完全一样！

⭕ 为什么圆会"贴"在边上？

我们用圆规画的圆，半径正好等于内心到边的距离。

因为：

  • 圆心在内心 \(I\)
  • 半径 = 内心到边的距离
  • 所以圆刚好"贴"在三条边上，不多也不少！
📍 切点在哪里？

圆和边"贴"在一起的那个点叫做切点。从内心画一条垂线到边，垂足就是切点！

在下面的图中，你可以看到三条灰色的虚线，它们是从内心到三条边的垂线，垂足就是切点 \(D\)、\(E\)、\(F\)。

✅ 完成了！我们画的圆确实和三角形的三条边都"贴"在一起了！这就是内切圆！
