一、数的分类

自然数 (N)

1, 2, 3, 4, 5, ...

从1开始的正整数

⊂

整数 (Z)

..., -2, -1, 0, 1, 2, ...

包括负整数、0和正整数

⊂

有理数 (Q)

可以表示为分数形式的数

包括整数和分数

📚 关系说明

  • 自然数是最基本的数，用于计数
  • 整数扩展了自然数，加入了0和负数
  • 有理数包括所有可以写成两个整数之比的数
  • 它们之间的关系是：自然数 ⊂ 整数 ⊂ 有理数

二、数轴

数轴是一条直线，上面标有数字。原点（0）在中间，正数在右边，负数在左边。 数轴帮助我们直观地理解数的大小关系和位置。

五、重要公式

绝对值的定义

对于任意实数 \(a\)：

\[|a| = \begin{cases} a & \text{如果 } a \geq 0 \\ -a & \text{如果 } a < 0 \end{cases}\]

绝对值的几何意义

数轴上，一个数的绝对值表示该数到原点的距离。

\[|a| = \text{点 } a \text{ 到原点的距离}\]

对称点

关于原点对称的两个数互为相反数：

\[\text{如果 } a \text{ 和 } -a \text{ 关于原点对称，则 } a + (-a) = 0\]
