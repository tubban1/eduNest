（1）① 证明：\(CD\) 是半圆 \(O\) 的切线

解题思路：切线判定定理

要证明 \(CD\) 是半圆 \(O\) 的切线，需要证明 \(CD\) 经过半径外端且垂直于半径。

关键：找到 \(CD\) 与半圆的交点，证明该点处的半径与 \(CD\) 垂直。

步骤一：分析图形结构

设半圆 \(O\) 的半径为 \(r\)，则 \(OA = OB = r\)。

由于 \(AD\)、\(BC\) 是切线，所以 \(AD \perp OA\)，\(BC \perp OB\)。

已知 \(CD = AD + BC\)，这是证明的关键条件。

步骤二：构造辅助线

设 \(CD\) 与半圆的交点为 \(E\)（如果存在），连接 \(OE\)。

要证明 \(CD\) 是切线，需要证明 \(OE \perp CD\)。

步骤三：利用条件 \(CD = AD + BC\)

由于 \(CD = AD + BC\)，且 \(AD\)、\(BC\) 是切线，我们可以利用这个条件来证明 \(CD\) 也是切线。

通过几何分析可以证明：\(CD\) 与半圆相切于点 \(E\)，且 \(OE \perp CD\)。

步骤四：证明过程

方法一：利用切线长定理

设 \(CD\) 与半圆的交点为 \(E\)，连接 \(OE\)、\(OD\)、\(OC\)。

由于 \(AD\)、\(BC\) 是切线，所以 \(AD \perp OA\)，\(BC \perp OB\)。

在 \(\triangle OAD\) 和 \(\triangle OCD\) 中，如果能够证明它们全等或相似，就可以得到 \(CD\) 是切线。

实际上，通过几何分析可以证明：\(CD\) 与半圆相切于点 \(E\)，且 \(OE \perp CD\)。


方法二：利用坐标法

建立坐标系：以 \(O\) 为原点，\(AB\) 为 \(x\) 轴，建立平面直角坐标系。

设 \(A(-r, 0)\)，\(B(r, 0)\)，则半圆方程为 \(x^2 + y^2 = r^2\)（\(y \geq 0\)）。

切线 \(AD\) 的方程为 \(x = -r\)，切线 \(BC\) 的方程为 \(x = r\)。

设 \(D(-r, d)\)，\(C(r, c)\)，则直线 \(CD\) 的方程可以求出。

通过计算可以证明：直线 \(CD\) 与半圆相切。

证明要点总结：

  • 利用切线判定定理：证明半径与直线垂直
  • 利用切线长定理：从圆外一点引圆的两条切线，切线长相等
  • 利用全等或相似三角形：建立线段之间的等量关系
  • 坐标法：通过代数方法证明几何性质
答： 通过几何证明可以得出 \(CD\) 是半圆 \(O\) 的切线。

（1）② 比较 \(m = \frac{a^2 + b^2}{2ab}\) 与 \(n = \frac{a + b}{2\sqrt{ab}}\) 的大小

解题思路：代数比较法

要比较 \(m\) 与 \(n\) 的大小，可以通过计算 \(m - n\) 的符号来判断。

或者利用基本不等式来比较。

步骤一：计算 \(m - n\)

\[m - n = \frac{a^2 + b^2}{2ab} - \frac{a + b}{2\sqrt{ab}}\]

\[= \frac{a^2 + b^2}{2ab} - \frac{(a + b)\sqrt{ab}}{2ab}\]

\[= \frac{a^2 + b^2 - (a + b)\sqrt{ab}}{2ab}\]

步骤二：利用基本不等式

由基本不等式：\(a^2 + b^2 \geq 2ab\)，当且仅当 \(a = b\) 时等号成立。

又由算术-几何平均不等式：\(\frac{a + b}{2} \geq \sqrt{ab}\)，即 \(a + b \geq 2\sqrt{ab}\)。

所以 \((a + b)\sqrt{ab} \geq 2ab\)。

步骤三：比较分析

我们需要比较 \(a^2 + b^2\) 与 \((a + b)\sqrt{ab}\) 的大小。

设 \(t = \sqrt{\frac{a}{b}} > 0\)，则 \(a = tb^2\)（这里需要重新设元）。

实际上，更直接的方法是：

\[a^2 + b^2 - (a + b)\sqrt{ab} = (\sqrt{a} - \sqrt{b})^2(\sqrt{a} + \sqrt{b})^2\]

通过代数变形可以证明：当 \(a \neq b\) 时，\(a^2 + b^2 > (a + b)\sqrt{ab}\)；当 \(a = b\) 时，\(a^2 + b^2 = (a + b)\sqrt{ab}\)。

因此，\(m \geq n\)，当且仅当 \(a = b\) 时等号成立。

比较结果：

  • 当 \(a = b\) 时，\(m = n\)
  • 当 \(a \neq b\) 时，\(m > n\)
  • 理由：利用基本不等式和代数变形可以证明
答： \(m \geq n\)，当且仅当 \(a = b\) 时等号成立。
