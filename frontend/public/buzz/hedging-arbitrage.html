一、最简单的示例：无风险套利公式（基础版）

🎯 什么是对冲（Hedging）？

对冲的核心概念：

  • 定义：对冲是一种金融策略，通过构建一个投资组合来抵消另一个投资的风险。
  • 目标：无论市场如何变化，组合的总价值保持稳定，实现"无风险"状态。
  • 原理：如果两个资产的价格变化方向相反或相关，我们可以通过适当的比例组合它们，消除不确定性。
  • 应用：期权定价、风险管理、套利交易等金融工程领域。

📚 单期二叉树模型

假设场景：

  • 今天买入某资产价格：S₀
  • 明天资产有两种可能：上涨到 Sᵤ 或下跌到 S𝒹
  • 无风险利率：r
  • 如果存在一个衍生品，它在两种状态下的价值分别为：上涨价值 Vᵤ，下跌价值 V𝒹

🔑 核心思想：复制组合（Replicating Portfolio）

我们要构造一个组合（买 Δ 份股票 + 借款 B），使得：

  • 无论资产上涨还是下跌，这个组合的价值都与衍生品相同
  • 如果组合完美复制了衍生品的支付，那么它们的当前价格必须相等（无套利原理）
  • 通过求解线性方程组，我们可以找到 Δ 和 B 的值

💡 关键洞察：如果我们能够用股票和债券的组合完美复制一个衍生品，那么这个衍生品的价格就等于复制组合的成本。这就是著名的"无套利定价原理"。

🎯 价值公式：

Δ = (Vᵤ - V𝒹) / (Sᵤ - S𝒹)
B = (Vᵤ - Δ × Sᵤ) / (1 + r)
V₀ = Δ × S₀ - B

V₀ 就是衍生品今天的公平价格

💰 如何利用对冲盈利？

策略：如果市场上衍生品的实际交易价格 V_market 与我们计算的公平价格 V₀ 不同，就存在套利机会！

  • 如果 V_market > V₀（衍生品被高估）：
    • 卖出衍生品（获得 V_market）
    • 买入复制组合（花费 V₀ = {{ basic.result.V0.toFixed(2) }}）
    • 利润 = V_market - V₀（无风险！）
  • 如果 V_market < V₀（衍生品被低估）：
    • 买入衍生品（花费 V_market）
    • 卖空复制组合（获得 V₀ = {{ basic.result.V0.toFixed(2) }}）
    • 利润 = V₀ - V_market（无风险！）

✨ 关键点：复制组合完美复制了衍生品的支付，所以无论市场如何变化，组合价值总是等于衍生品价值，利润被锁定！

二、中级例子：加入期权（看跌期权）

📖 看跌期权（Put Option）基础

什么是看跌期权？

  • 定义：看跌期权给予持有者在到期日以执行价格 K 卖出标的资产的权利（而非义务）。
  • 价值公式：Put 的价值 = max(K - S, 0)，当资产价格 S 低于执行价格 K 时才有价值。
  • Delta（Δ）：对于看跌期权，Delta 通常为负值，表示期权价值与资产价格反向变化。
  • 对冲策略：卖出股票来对冲 Put 期权的风险（因为 Delta 为负）。

🔍 为什么 Delta 是负数？

对于看跌期权：

  • 当资产价格上涨时，Put 价值下降（更不可能被执行）
  • 当资产价格下跌时，Put 价值上升（更可能被执行）
  • 因此，Δ = ∂V/∂S < 0（负相关）
  • 对冲时需要卖出股票，而不是买入

💡 场景：套利一个欧洲看跌期权（Put Option）
关键特点：看跌期权的价值 = max(K - S, 0)，其中 K 是执行价格

📊 计算结果：
第一步：计算期权未来价值

Vᵤ = max(K - Sᵤ, 0) = max({{ intermediate.K }} - {{ intermediate.Su }}, 0) = {{ intermediate.result.Vu }}

V𝒹 = max(K - S𝒹, 0) = max({{ intermediate.K }} - {{ intermediate.Sd }}, 0) = {{ intermediate.result.Vd }}

第二步：求 Delta (Δ)

Δ = (Vᵤ - V𝒹) / (Sᵤ - S𝒹)

= ({{ intermediate.result.Vu }} - {{ intermediate.result.Vd }}) / ({{ intermediate.Su }} - {{ intermediate.Sd }})

= {{ (intermediate.result.Vu - intermediate.result.Vd).toFixed(2) }} / {{ (intermediate.Su - intermediate.Sd).toFixed(2) }}

Δ = {{ intermediate.result.delta.toFixed(4) }} (负值表示需要卖出股票来对冲 Put)

第三步：求借款 B

B = (Vᵤ - Δ × Sᵤ) / (1 + r)

= ({{ intermediate.result.Vu }} - ({{ intermediate.result.delta.toFixed(4) }}) × {{ intermediate.Su }}) / (1 + {{ (intermediate.r / 100).toFixed(2) }})

= {{ (intermediate.result.Vu - intermediate.result.delta * intermediate.Su).toFixed(2) }} / {{ (1 + intermediate.r / 100).toFixed(2) }}

B = {{ intermediate.result.B.toFixed(2) }}

第四步：求期权价格（使用风险中性概率）

或者使用复制组合法：

V₀ = Δ × S₀ - B = ({{ intermediate.result.delta.toFixed(4) }}) × {{ intermediate.S0 }} - {{ intermediate.result.B.toFixed(2) }}

= {{ (intermediate.result.delta * intermediate.S0).toFixed(2) }} - {{ intermediate.result.B.toFixed(2) }}

= {{ intermediate.result.V0.toFixed(2) }}

使用风险中性概率法：

q = {{ intermediate.result.q }}（上涨概率）

P₀ = [q × Vᵤ + (1-q) × V𝒹] / (1 + r)

= [{{ intermediate.result.q }} × {{ intermediate.result.Vu }} + (1-{{ intermediate.result.q }}) × {{ intermediate.result.Vd }}] / {{ (1 + intermediate.r / 100).toFixed(2) }}

Put 期权价格 P₀ = {{ intermediate.result.P0.toFixed(2) }}

💰 如何通过对冲看跌期权盈利？

策略一：卖出被高估的 Put 期权 + Delta 对冲

  1. 卖出 Put 期权：如果市场价格 P_market > 理论价格 P₀ = {{ intermediate.result.P0.toFixed(2) }}，卖出期权获得收入
  2. 构造 Delta 对冲组合：
    • 卖出 {{ Math.abs(intermediate.result.delta).toFixed(4) }} 份股票（因为 Δ = {{ intermediate.result.delta.toFixed(4) }} < 0）
    • 借出资金 {{ intermediate.result.B.toFixed(2) }} 元
  3. 锁定利润：无论资产价格上涨还是下跌，对冲组合都会完美复制 Put 的支付
  4. 无风险利润：P_market - P₀ = 利润（被锁定，无风险！）

策略二：买入被低估的 Put 期权 + 反向对冲

  1. 买入 Put 期权：如果市场价格 P_market < 理论价格 P₀ = {{ intermediate.result.P0.toFixed(2) }}，买入期权
  2. 构造反向对冲：
    • 买入 {{ Math.abs(intermediate.result.delta).toFixed(4) }} 份股票（与 Delta 相反）
    • 借入资金 {{ intermediate.result.B.toFixed(2) }} 元
  3. 锁定利润：P₀ - P_market = 利润（无风险！）

✨ 关键洞察：Delta 对冲消除了资产价格波动的风险，无论市场涨跌，利润都被完美锁定！这就是期权交易中"市场中性"策略的核心。

三、复杂例子：加入市场价格偏差导致套利

💰 什么是套利（Arbitrage）？

套利的定义：

  • 定义：利用同一资产在不同市场或不同形式下的价格差异，通过同时买卖获得无风险利润。
  • 核心特征：无风险、无投入（或净投入为零）、立即盈利。
  • 前提条件：市场存在定价错误或偏差。
  • 结果：套利行为会迅速消除价格差异，使市场回归均衡。

🎯 套利策略的核心思想

当市场价格偏离理论价格时：

  1. 识别偏差：发现市场价格与理论价格（通过复制组合计算）不一致
  2. 构造对冲组合：卖出被高估的资产，同时买入复制组合
  3. 锁定利润：由于组合完美复制了资产，无论市场如何变化，都能获得确定的利润
  4. 风险中性：通过 Delta 对冲，消除了所有市场风险

📊 示例数据说明

  • 理论价格 P_fair = 10.71：通过对冲公式计算得出的公平价格
  • 市场价格 P_market = 16：市场实际交易价格（被高估）
  • 套利利润 = 16 - 10.71 = 5.29：无风险利润！

⚠️ 重要提示：在真实市场中，套利机会通常非常短暂。一旦发现，大量套利者会迅速行动，使价格回归均衡。这正是金融市场的效率体现！
