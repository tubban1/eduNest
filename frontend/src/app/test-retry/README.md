# 重试功能测试页面

## 功能说明

这个测试页面用于调试和验证异步内容生成的重试功能。

## 访问方式

访问 `/test-retry` 页面即可使用。

## 测试功能

### 1. 模拟测试卡片

页面提供三个预设的测试卡片：

- **等待中卡片** (`pending`): 显示灰色占位符，模拟等待生成的状态
- **生成中卡片** (`processing`): 显示进度条，模拟正在生成的状态  
- **失败卡片** (`failed`): 显示错误信息和重试按钮，模拟生成失败的状态

### 2. 真实API测试

点击"创建真实测试内容"按钮可以：

- 创建一个真实的内容记录
- 启动异步生成流程
- 测试完整的生成和重试流程

### 3. 重试功能测试

在失败卡片上：

- 点击"重试"按钮测试重试功能
- 观察重试计数的变化
- 验证状态是否正确重置

### 4. 调试日志

页面底部提供实时调试日志：

- 显示所有操作的时间戳和详细信息
- 记录API调用和响应
- 跟踪状态变化过程

## 测试步骤

### 基础测试

1. 访问测试页面
2. 观察三个不同状态的卡片
3. 点击失败卡片的"重试"按钮
4. 观察状态变化和日志输出

### 真实API测试

1. 确保已登录
2. 点击"创建真实测试内容"
3. 观察新卡片的状态变化
4. 等待生成完成或失败
5. 测试重试功能

### 调试重试计数

1. 创建多个测试内容
2. 让它们都失败
3. 点击重试按钮
4. 验证重试计数是否正确重置

## 预期行为

### 重试按钮

- 失败状态时显示"重试"按钮
- 点击后按钮显示"重试中..."
- 重试后状态重置为 `pending`
- 重试计数重置为 0

### 状态流程

```
failed → 点击重试 → pending → processing → done/failed
```

### 重试计数

- 显示格式: "自动重试 X/2"
- 手动重试后重置为 "自动重试 0/2"
- 自动重试时递增: 1/2, 2/2

## 常见问题

### 1. 重试后状态不变

检查：
- 网络连接是否正常
- 后端服务是否运行
- 查看调试日志中的错误信息

### 2. 重试计数显示错误

检查：
- 后端重试计数计算逻辑
- 前端状态更新是否正确
- 数据库记录是否正确

### 3. 状态轮询卡住

检查：
- 前端轮询是否正常启动
- 后端状态是否正确更新
- 是否有JavaScript错误

## 技术实现

### 前端组件

- `PendingCard`: 等待状态卡片
- `ProcessingCard`: 生成中状态卡片  
- `FailedCard`: 失败状态卡片

### API接口

- `api.retryFailedTask()`: 重试失败任务
- `api.generateContentAsync()`: 异步生成内容
- `api.getContentGenerationStatus()`: 获取生成状态

### 状态管理

- 使用React状态管理组件状态
- 实时日志记录调试信息
- 模拟状态变化进行测试
