# 🧪 前端Stripe集成测试指南

## 📋 测试环境准备

### 1. 后端服务器
```bash
# 在edu/backend目录下
npm start
# 确保服务器运行在 http://localhost:3001
```

### 2. 前端服务器
```bash
# 在edu/frontend目录下
npm run dev
# 确保服务器运行在 http://localhost:3000
```

### 3. Stripe CLI监听
```bash
# 在edu/backend目录下
stripe listen --forward-to localhost:3001/api/payments/webhook
```

## 🎯 测试流程

### 步骤1: 访问测试页面
1. 打开浏览器访问: `http://localhost:3000/test-payment`
2. 确认页面正常加载，显示"Stripe支付测试页面"

### 步骤2: 用户认证
1. 确保用户已登录（如果没有登录，先登录）
2. 检查浏览器控制台是否有认证token

### 步骤3: 测试支付流程
1. 点击"测试Pro订阅支付"按钮
2. 观察是否成功创建支付会话
3. 检查是否重定向到Stripe Checkout页面

### 步骤4: 完成支付
1. 在Stripe Checkout页面使用测试卡号: `4242 4242 4242 4242`
2. 填写任意未来日期和任意CVC
3. 点击"Pay"完成支付

### 步骤5: 验证结果
1. 支付成功后应该重定向到: `http://localhost:3000/subscription/success`
2. 取消支付应该重定向到: `http://localhost:3000/subscription/cancel`
3. 检查webhook是否收到事件

## 🐛 常见问题排查

### 1. 认证失败
- 检查token是否有效
- 确认后端认证中间件配置
- 查看浏览器控制台错误信息

### 2. 支付会话创建失败
- 检查Stripe环境变量配置
- 确认后端服务器正常运行
- 查看后端日志错误信息

### 3. 重定向失败
- 检查success_url和cancel_url配置
- 确认前端路由正确设置
- 查看浏览器网络请求

### 4. Webhook事件未收到
- 确认Stripe CLI正在监听
- 检查webhook端点配置
- 查看webhook处理逻辑
