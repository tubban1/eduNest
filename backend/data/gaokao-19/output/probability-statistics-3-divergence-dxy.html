概率与统计新定义（3）相似程度指标 D(X‖Y)

题目

(2024·北京·高三阶段练习) 设离散型随机变量 \(X\) 和 \(Y\) 有相同的可能取值，它们的分布列分别为 \(P(X=a_k)=x_k\)，\(P(Y=a_k)=y_k\)，\(x_k > 0\)，\(y_k > 0\)，\(k=1, 2, \cdots, n\)，\(\sum_{k=1}^{n} x_k=\sum_{k=1}^{n} y_k=1\)．指标 \(D(X \| Y)\) 可用来刻画 \(X\) 和 \(Y\) 的相似程度，其定义为 \(D(X \| Y)=\sum_{k=1}^{n} x_k \ln \frac{x_k}{y_k}\)．设 \(X \sim B(n, p)\)，\(0 < p < 1\)．

(1)若 \(Y \sim B(n, q)\)，\(0 < q < 1\)，求 \(D(X \| Y)\)；

(2)若 \(n=2\)，\(P(Y=k - 1)=\frac{1}{3}\)，\(k=1, 2, 3\)，求 \(D(X \| Y)\) 的最小值；

(3)对任意与 \(X\) 有相同可能取值的随机变量 \(Y\)，证明：\(D(X \| Y) \geq 0\)，并指出取等号的充要条件．

启发引导

问题背景：KL 散度（Kullback-Leibler Divergence），也称为相对熵，常用于衡量两个概率分布 \(X\) 和 \(Y\) 之间的差异。定义为 \(D(X\|Y)=\sum x_k \ln \frac{x_k}{y_k}\)。

直观理解：
1. 非负性：\(D(X\|Y) \geq 0\)，当且仅当 \(X\) 和 \(Y\) 分布完全一致时取 0。
2. 不对称性：通常 \(D(X\|Y) \neq D(Y\|X)\)，所以它不是严格意义上的“距离”，而是“相似度指标”。
3. 物理意义：它衡量的是用分布 \(Y\) 来近似分布 \(X\) 时所损失的信息量。

本题思路：
第(1)问：代入二项分布公式，利用对数性质 \( \ln(ab)=\ln a+\ln b \) 拆分求和。
第(2)问：构建关于 \(p\) 的函数，利用导数求极值。注意 \(p \in (0, 1)\) 的范围。
第(3)问：利用 \(\ln x \leq x-1\) （切线不等式）放缩，证明 \(D \geq 0\)。

第(1)问

设元：\(X\sim B(n, p)\)，\(Y\sim B(n, q)\)，取值为 \(0, 1, \cdots, n\)。

列式与化简：代入 \(x_k\) 和 \(y_k\) 的二项分布公式，化简得： \[ D(X\|Y)=n\left(p\ln\frac{p}{q}+(1-p)\ln\frac{1-p}{1-q}\right). \]

答：\(\boxed{D(X\|Y)=n\left(p\ln\dfrac{p}{q}+(1-p)\ln\dfrac{1-p}{1-q}\right)}\)。

观察：当 p=q 时，分布重合，D=0。当 p 与 q 差异越大，红蓝柱子差异越大，D 越大。

第(2)问

条件：\(n=2\)，\(X\sim B(2,p)\)，故 \(P(X=0)=(1-p)^2\)，\(P(X=1)=2p(1-p)\)，\(P(X=2)=p^2\)；\(Y\) 满足 \(P(Y=0)=P(Y=1)=P(Y=2)=\dfrac{1}{3}\)（均匀分布）。

列式：由定义 \[ D(X\|Y) = \sum_{k=0}^{2} x_k \ln\frac{x_k}{y_k} = (1-p)^2\ln\frac{(1-p)^2}{1/3} + 2p(1-p)\ln\frac{2p(1-p)}{1/3} + p^2\ln\frac{p^2}{1/3}. \] 记 \(f(p)=D(X\|Y)\)（\(p\in(0,1)\)），展开并利用 \(\ln(ab)=\ln a+\ln b\) 可写成 \(f(p)\) 关于 \(p\) 的式子。

求导：对 \(p\) 求导得 \(f'(p)\)。利用 \(\dfrac{\mathrm{d}}{\mathrm{d}p}\bigl[(1-p)^2\ln(1-p)\bigr]\) 等项合并后，\(f'(p)\) 可化简为形如 \((2p-1)\cdot g(p)\)（其中 \(g(p)>0\) 在 \((0,1)\) 内），故 \(f'(p)=0\) 在 \((0,1)\) 内仅有 \(p=\dfrac{1}{2}\)；又 \(f''\!\bigl(\tfrac{1}{2}\bigr)>0\)，故 \(p=\dfrac{1}{2}\) 时 \(f(p)\) 取最小值。

代入求值：\(p=\dfrac{1}{2}\) 时 \(x_0=\dfrac{1}{4}\)，\(x_1=\dfrac{1}{2}\)，\(x_2=\dfrac{1}{4}\)，故 \[ f\!\left(\tfrac{1}{2}\right) = \frac{1}{4}\ln\frac{3}{4} + \frac{1}{2}\ln\frac{3}{2} + \frac{1}{4}\ln\frac{3}{4} = \frac{1}{2}\ln\frac{3}{4} + \frac{1}{2}\ln\frac{3}{2} = \frac{1}{2}\ln\frac{9}{8} = \ln 3 - \frac{3}{2}\ln 2. \]

答：\(D(X\|Y)\) 的最小值为 \(\boxed{\ln 3 - \dfrac{3}{2}\ln 2}\)，当且仅当 \(p=\dfrac{1}{2}\) 时取得。

第(3)问

结论：对任意与 \(X\) 同取值且 \(y_k>0\) 的 \(Y\)，有 \(D(X\|Y)\geq 0\)，等号成立当且仅当对一切 \(k\) 有 \(x_k=y_k\)（即 \(X\) 与 \(Y\) 同分布）。

证明：利用不等式 \(\ln t \leq t-1\)（\(t>0\)），等号成立当且仅当 \(t=1\)。令 \(t=\dfrac{y_k}{x_k}\)，则 \(\ln\dfrac{y_k}{x_k} \leq \dfrac{y_k}{x_k}-1\)，即 \(\ln\dfrac{x_k}{y_k} \geq 1-\dfrac{y_k}{x_k}\)。两边同乘 \(x_k>0\) 得 \(x_k\ln\dfrac{x_k}{y_k} \geq x_k - y_k\)。对 \(k=1,\ldots,n\) 求和得 \[ D(X\|Y) = \sum_{k=1}^n x_k \ln\frac{x_k}{y_k} \geq \sum_{k=1}^n (x_k - y_k) = \sum_{k=1}^n x_k - \sum_{k=1}^n y_k = 1-1 = 0. \]

等号条件：\(D(X\|Y)=0\) 当且仅当对每个 \(k\) 都有 \(\ln\dfrac{x_k}{y_k} = \dfrac{x_k}{y_k}-1\) 的等号成立，即 \(\dfrac{x_k}{y_k}=1\)，亦即 \(x_k=y_k\) 对所有 \(k\) 成立，故 \(X\) 与 \(Y\) 同分布。

答：\(D(X\|Y)\geq 0\)；取等当且仅当 \(X\) 与 \(Y\) 的分布列相同。

总结与验证

定义：\(D(X\|Y)=\sum_{k=1}^n x_k \ln\dfrac{x_k}{y_k}\)，其中 \(x_k=P(X=a_k)\)，\(y_k=P(Y=a_k)\)，\(\sum x_k=\sum y_k=1\)。\(D\) 衡量用分布 \(Y\) 近似 \(X\) 时的“信息损失”，非对称。

(1) \(X\sim B(n,p)\)，\(Y\sim B(n,q)\) 时 \(D(X\|Y)=n\left(p\ln\dfrac{p}{q}+(1-p)\ln\dfrac{1-p}{1-q}\right)\)；当 \(p=q\) 时 \(D=0\)。

(2) \(n=2\) 且 \(Y\) 为取值 \(0,1,2\) 上的均匀分布（各 \(\dfrac{1}{3}\)）时，\(D(X\|Y)\) 在 \(p=\dfrac{1}{2}\) 时取最小值 \(\ln 3-\dfrac{3}{2}\ln 2\)。

(3) 对任意与 \(X\) 同取值且 \(y_k>0\) 的 \(Y\)，有 \(D(X\|Y)\geq 0\)；等号当且仅当 \(x_k=y_k\)（\(\forall k\)），即 \(X\) 与 \(Y\) 同分布。证明核心为 \(\ln t \leq t-1\)（\(t>0\)）代入 \(t=x_k/y_k\) 后求和。

易错：\(D(X\|Y)\neq D(Y\|X)\)；求最小值时注意 \(p\in(0,1)\) 为开区间，驻点 \(p=1/2\) 在区间内故有效。
