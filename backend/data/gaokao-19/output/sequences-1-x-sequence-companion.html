数列新定义（1）X 数列与伴随数列

题目

(2024·北京·高三北京市第五中学校考阶段练习) 若数列 \(\{a_n\}\) 满足：\(a_n \in \{0,1\},\, n \in \mathbb{N}^*\)，且 \(a_1 = 1\)，则称 \(\{a_n\}\) 为一个X 数列．对于一个 X 数列 \(\{a_n\}\)，若数列 \(\{b_n\}\) 满足：\(b_1 = 1\)，且 \(b_{n+1} = \left|a_n - \dfrac{a_{n+1}}{2}\right| b_n,\, n \in \mathbb{N}^*\)，则称 \(\{b_n\}\) 为 \(\{a_n\}\) 的伴随数列．

(1) 若 X 数列 \(\{a_n\}\) 中，\(a_2 = 1\)，\(a_3 = 0\)，\(a_4 = 1\)，写出其伴随数列 \(\{b_n\}\) 中 \(b_2, b_3, b_4\) 的值；

(2) 若 \(\{a_n\}\) 为一个 X 数列，\(\{b_n\}\) 为 \(\{a_n\}\) 的伴随数列．
① 证明：“\(\{a_n\}\) 为常数列”是“\(\{b_n\}\) 为等比数列”的充要条件；
② 求 \(b_{2019}\) 的最大值．

启发引导

核心机制：
1. X 数列 \(a_n\)：只能取 0 或 1，且 \(a_1\) 必须为 1。
2. 伴随数列 \(b_n\)：

  • \(b_1 = 1\)；\(b_{n+1} = \left|a_n - \dfrac{a_{n+1}}{2}\right| b_n\)。

第(1)问

已知：\(a_1=1,\,a_2=1,\,a_3=0,\,a_4=1\)。由题设 \(b_1=1\)，\(b_{n+1}=\left|a_n-\dfrac{a_{n+1}}{2}\right|b_n\)。

代入公式计算：

  • \(b_1 = 1\)。
  • \(b_2 = \left|a_1-\dfrac{a_2}{2}\right|b_1 = \left|1-\dfrac{1}{2}\right|\cdot 1 = \dfrac{1}{2}\)。
  • \(b_3 = \left|a_2-\dfrac{a_3}{2}\right|b_2 = \left|1-\dfrac{0}{2}\right|\cdot \dfrac{1}{2} = \dfrac{1}{2}\)。
  • \(b_4 = \left|a_3-\dfrac{a_4}{2}\right|b_3 = \left|0-\dfrac{1}{2}\right|\cdot \dfrac{1}{2} = \dfrac{1}{4}\)。

答：\(b_2=\dfrac{1}{2}\)，\(b_3=\dfrac{1}{2}\)，\(b_4=\dfrac{1}{4}\)。

第(2)问

① 证明（充要条件）

由 \(b_{n+1}=\left|a_n-\dfrac{a_{n+1}}{2}\right|b_n\)：\((1,1)\) 与 \((0,1)\) 得 \(b_{n+1}=\dfrac{1}{2}b_n\)，\((1,0)\) 得 \(b_{n+1}=b_n\)，\((0,0)\) 得 \(b_{n+1}=0\)。

充分性：若 \(\{a_n\}\) 为常数列，由 \(a_1=1\) 知 \(a_n\equiv 1\)，则 \(b_{n+1}=\left|1-\dfrac{1}{2}\right|b_n=\dfrac{1}{2}b_n\)，故 \(b_n=\dfrac{1}{2^{n-1}}\)，\(\{b_n\}\) 为公比 \(\dfrac{1}{2}\) 的等比数列。

必要性：设 \(\{b_n\}\) 为等比数列且 \(b_1=1\)。若某步为 \((0,0)\) 则 \(b_{n+1}=0\)，之后恒为 0，与等比且 \(b_1=1\) 矛盾（或仅视为公比 0）。故不能出现 \((0,0)\)。若出现 \((1,0)\) 则 \(b_{n+1}=b_n\) 不衰减；若出现 \((1,1)\) 或 \((0,1)\) 则乘 \(\dfrac{1}{2}\)。要使 \(\{b_n\}\) 为等比，需递推形式一致：若 \(b_2=\dfrac{1}{2}\) 则每步均为乘 \(\dfrac{1}{2}\)，即不能出现 \((1,0)\)，故 \(a_n\) 不能有 0 后继 1 的交替中的“1,0”段，只能全为 1，即 \(\{a_n\}\) 为常数列。

② 求 \(b_{2019}\) 的最大值

\(b_{n+1}=\left|a_n-\dfrac{a_{n+1}}{2}\right|b_n \le b_n\)，等号当且仅当 \((a_n,a_{n+1})=(1,0)\) 时 \(b_{n+1}=b_n\)（不衰减）；\((1,1)\) 与 \((0,1)\) 时 \(b_{n+1}=\dfrac{1}{2}b_n\)。要使 \(b_{2019}\) 最大，应尽量多出现 \((1,0)\)。取 \(a_n\) 为 \(1,0,1,0,\dots\)：\(b_2=|1-0|b_1=b_1=1\)，\(b_3=\left|0-\dfrac{1}{2}\right|b_2=\dfrac{1}{2}\)，\(b_4=|1-0|b_3=b_3=\dfrac{1}{2}\)，\(b_5=\dfrac{1}{2}b_4=\dfrac{1}{4}\)，…，即 \(b_{2k}=b_{2k+1}=\dfrac{1}{2^k}\)。故 \(b_{2019}=b_{2\times 1009+1}=\dfrac{1}{2^{1009}}\)。

答：\(b_{2019}\) 的最大值为 \(\dfrac{1}{2^{1009}}\)。

总结与验证

递推：\(b_{n+1}=\left|a_n-\dfrac{a_{n+1}}{2}\right|b_n\)。\(a_n,a_{n+1}\in\{0,1\}\) 时：\((1,1)\)、\((0,1)\) 得 \(b_{n+1}=\dfrac{1}{2}b_n\)；\((1,0)\) 得 \(b_{n+1}=b_n\)；\((0,0)\) 得 \(b_{n+1}=0\)。

(1) \(a_1=1,\,a_2=1,\,a_3=0,\,a_4=1\) 时，\(b_2=\dfrac{1}{2},\,b_3=\dfrac{1}{2},\,b_4=\dfrac{1}{4}\)。

(2)① “\(\{a_n\}\) 为常数列”当且仅当“\(\{b_n\}\) 为等比数列”：常数列（\(a_n\equiv 1\)）时 \(b_n=\dfrac{1}{2^{n-1}}\)（公比 \(\dfrac{1}{2}\)）；\(\{b_n\}\) 为等比且 \(b_1=1\) 时，\(\{a_n\}\) 必为常数列。

(2)② \(b_{2019}\) 的最大值为 \(\dfrac{1}{2^{1009}}\)。在 \(a_n=1,0,1,0,\dots\) 时取得，此时 \(b_{2k}=b_{2k+1}=\dfrac{1}{2^k}\)（\(k\ge 1\)），故 \(b_{2019}=\dfrac{1}{2^{1009}}\)。
