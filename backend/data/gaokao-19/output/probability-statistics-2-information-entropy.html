概率与统计新定义（2）信息熵

题目

(2024·河北·高三雄县第一高级中学校联考期末) 在信息论中，熵 (entropy)是接收的每条消息中包含的信息的平均量，又被称为信息熵、信源熵、平均自信息量．这里，“消息”代表来自分布或数据流中的事件、样本或特征．（熵最好理解为不确定性的量度而不是确定性的量度，因为越随机的信源的熵越大．）来自信源的另一个特征是样本的概率分布．这里的想法是，比较不可能发生的事情，当它发生了，会提供更多的信息．由于一些其他的原因，把信息（熵）定义为概率分布的对数的相反数是有道理的．事件的概率分布和每个事件的信息量构成了一个随机变量，这个随机变量的均值（即期望）就是这个分布产生的信息量的平均值（即熵）．熵的单位通常为比特，但也用 Sh、nat、Hart 计量，取决于定义用到对数的底．设随机变量 \(\xi\) 所有取值为 \(1, 2, \cdots, n\)，定义 \(\xi\) 的信息熵\(H(\xi)=-\sum_{i=1}^{n} P_i \log_2 P_i\)，其中 \(\sum_{i=1}^{n} P_i=1\)，\(i=1, 2, \cdots, n\)．

(1)若 \(n=2\)，试探索 \(\xi\) 的信息熵关于 \(P_1\) 的解析式，并求其最大值；

(2)若 \(P_1=P_2=\frac{1}{2^{n-1}}\)，\(P_{k+1}=2 P_k\)（\(k=2, 3, \cdots, n\)），求此时的信息熵．

启发引导

问题描述：信息熵 \(H(\xi)\) 是衡量随机变量不确定性的指标。定义为 \(H(\xi)=-\sum P_i \log_2 P_i\)。本题研究两种情况下的信息熵：(1) 二元分布 (\(n=2\))；(2) 特殊递推分布。

题意拆解：
1. 核心概念：熵越大，不确定性越高。对于二元分布（如抛硬币），当概率 \(p=0.5\) 时，结果最难预测，熵最大。
2. 任务：(1) \(n=2\) 时，设 \(P_1=p, P_2=1-p\)，寻找 \(H(p)\) 的最大值；(2) 给定递推关系 \(P_{k+1}=2P_k\) 且 \(P_1=P_2\)，求 \(H\) 的通项公式。

思路提示：
第(1)问：构造函数 \(H(p)=-p\log_2 p - (1-p)\log_2(1-p)\)，求导找极值点。利用 \(\ln(1/p)=-\ln p\)。
第(2)问：先由递推求出通项 \(P_k\)（等比数列），利用 \(\sum P_i=1\) 验证。代入熵公式，化简 \(-\sum P_k \log_2 P_k\)，利用错位相减法求和。

考点与易错：导数求最值、数列求和（错位相减）、对数运算性质。易错点是对数的底为 2，求导时需带上 \(\ln 2\) 因子（虽不影响驻点位置）。

第(1)问

设元：\(n=2\) 时 \(\xi\) 取 1、2，设 \(P_1=P(\xi=1)=p\)（\(0 < p < 1\)），则 \(P_2=1-p\)。

列式：由定义 \[ H(\xi)=-\sum_{i=1}^2 P_i\log_2 P_i=-p\log_2 p-(1-p)\log_2(1-p). \]

求最大值：求导得 \(H'(p)=\frac{1}{\ln 2}\ln\frac{1-p}{p}\)。令 \(H'(p)=0\) 得 \(p=1/2\)。此时 \(H(p)\) 最大。

答：解析式 \(H(P_1)=-P_1\log_2 P_1-(1-P_1)\log_2(1-P_1)\)；最大值为 \(\boxed{1}\)（当 \(P_1=1/2\) 时取得）。

改变 P1 (发生的概率)，观察信息熵 H(p) (不确定性) 的变化。

第(2)问

条件：\(P_1=P_2=\dfrac{1}{2^{n-1}}\)，\(P_{k+1}=2P_k\)（\(k=2, 3, \cdots, n\)）。

通项：由递推得 \(P_k = P_2\cdot 2^{k-2} = \dfrac{1}{2^{n-1}}\cdot 2^{k-2} = \dfrac{1}{2^{n-k+1}}\)（\(k=2, \ldots, n\)）。

\(P_k\log_2 P_k\)：\(P_k\log_2 P_k = \dfrac{1}{2^{n-k+1}}\log_2\dfrac{1}{2^{n-k+1}} = -\dfrac{n-k+1}{2^{n-k+1}}\)；\(P_1\log_2 P_1 = -\dfrac{n-1}{2^{n-1}}\)。

\(H(\xi)\)：\(H(\xi)=-\sum_{k=1}^n P_k\log_2 P_k = \dfrac{n-1}{2^{n-1}} + \sum_{k=2}^n \dfrac{n-k+1}{2^{n-k+1}}\)。令 \(j=n-k+1\) 可写成 \(H(\xi) = \dfrac{n-1}{2^{n-1}} + \dfrac{n-1}{2^{n-1}} + \dfrac{n-2}{2^{n-2}} + \cdots + \dfrac{1}{2}\)。

错位相减：令 \(S_n = \dfrac{1}{2}+\dfrac{2}{2^2}+\cdots+\dfrac{n}{2^n}\)，则 \(\dfrac{1}{2}S_n = \dfrac{1}{2^2}+\dfrac{2}{2^3}+\cdots+\dfrac{n}{2^{n+1}}\)，两式相减得 \(\dfrac{1}{2}S_n = \dfrac{1}{2}+\dfrac{1}{2^2}+\cdots+\dfrac{1}{2^n} - \dfrac{n}{2^{n+1}} = 1-\dfrac{1}{2^n} - \dfrac{n}{2^{n+1}} = 1 - \dfrac{n+2}{2^{n+1}}\)，故 \(S_n = 2 - \dfrac{n+2}{2^n}\)。

代入：整理得 \(H(\xi) = \dfrac{n-1}{2^{n-1}} - \dfrac{n}{2^n} + S_n = \dfrac{n-1}{2^{n-1}} - \dfrac{n}{2^n} + 2 - \dfrac{n+2}{2^n}\)，化简得 \(H(\xi) = \dfrac{2(n-1)-n-(n+2)}{2^n} + 2 = \dfrac{-4}{2^n} + 2 = 2 - \dfrac{1}{2^{n-2}}\)。

答：\(H(\xi) = \boxed{2 - \dfrac{1}{2^{n-2}}}\)。

总结与验证

(1) \(n=2\) 时 \(H(P_1)=-P_1\log_2 P_1-(1-P_1)\log_2(1-P_1)\)，最大值 1（当 \(P_1=1/2\)）。

(2) \(P_1=P_2=1/2^{n-1}\)，\(P_{k+1}=2P_k\) 时，\(P_k=1/2^{n-k+1}\)，错位相减得 \(H(\xi)=2-\dfrac{1}{2^{n-2}}\)。

回顾：信息熵衡量不确定性；概率均等时熵最大。
