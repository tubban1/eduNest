数列新定义（3）数列 S_n 与集合 P_t

题目

(2024·上海浦东新·华师大二附中校考模拟预测) 已知数列 \(\{a_n\}\)：1，−2，−2，3，3，3，−4，−4，−4，−4，⋯，\(\underbrace{(-1)^{k-1}k,\cdots,(-1)^{k-1}k}_{k\text{ 个}}\)，即当 \(\frac{(k-1)k}{2} < n \leq \frac{k(k+1)}{2}\)（\(k \in \mathbb{N}^*\)）时，\(a_n=(-1)^{k-1} k\)，记 \(S_n=a_1 + a_2 + \cdots + a_n\)（\(n \in \mathbb{N}^*\)）．

(1) 求 \(S_{2020}\) 的值；

(2) 求当 \(\frac{k(k+1)}{2} < n \leq \frac{(k+1)(k+2)}{2}\)（\(k \in \mathbb{N}^*\)）时，试用 \(n\)、\(k\) 的代数式表示 \(S_n\)（\(n \in \mathbb{N}^*\)）；

(3) 对于 \(t \in \mathbb{N}^*\)，定义集合 \(P_t = \{n \mid S_n \text{ 是 } a_n \text{ 的整数倍},\, n \in \mathbb{N}^*,\, \text{且 } 1 \leq n \leq t\}\)，求集合 \(P_{2020}\) 中元素的个数．

第(1)问

目标：求 \(S_{2020}\)。

步骤 1：确定 2020 所在组。前 \(k\) 组共 \(\dfrac{k(k+1)}{2}\) 项。令 \(\dfrac{k(k+1)}{2} < 2020 \le \dfrac{(k+1)(k+2)}{2}\)，得 \(k=63\) 时 \(\dfrac{63\cdot 64}{2}=2016\)，\(k=64\) 时 \(\dfrac{64\cdot 65}{2}=2080\)，故 2020 在第 64 组，该组通项为 \((-1)^{63}\cdot 64 = -64\)。

步骤 2：前 2016 项和 \(S_{2016}\)。前 \(k\) 组完整和 \(S_{\frac{k(k+1)}{2}} = \sum_{i=1}^k (-1)^{i-1} i^2 = (-1)^{k-1}\dfrac{k(k+1)}{2}\)。代入 \(k=63\) 得 \(S_{2016} = \dfrac{63\cdot 64}{2} = 2016\)。

步骤 3：\(S_{2020} = S_{2016} + 4\times(-64) = 2016 - 256 = 1760\)。

答：\(S_{2020} = 1760\)。

第(2)问

当 \(\dfrac{k(k+1)}{2} < n \le \dfrac{(k+1)(k+2)}{2}\)（\(k \in \mathbb{N}^*\)）时，\(n\) 落在第 \(k+1\) 组内，该组每项为 \((-1)^k (k+1)\)，从组首到当前项共 \(n - \dfrac{k(k+1)}{2}\) 项。

推导：\(S_n = S_{\frac{k(k+1)}{2}} + (-1)^k (k+1)\left(n - \dfrac{k(k+1)}{2}\right)\)。利用 \(S_{\frac{k(k+1)}{2}} = (-1)^{k-1}\dfrac{k(k+1)}{2}\)，整理得

\[ S_n = (-1)^{k-1}(k+1)\left(n - \dfrac{k(k+1)}{2} + \dfrac{k}{2}\right) = (-1)^{k-1}(k+1)\left(n - \dfrac{k^2+1}{2}\right). \]

题设区间对应的是“第 \(k+1\) 组”，若将组号记为 \(k\)（即题中 \(k\) 为当前组号），则 \(S_n = (-1)^{k-1} k \left(n - \dfrac{k^2-1}{2}\right)\)（\(n\) 在 \(\dfrac{(k-1)k}{2} < n \le \dfrac{k(k+1)}{2}\) 内）。

答：\(S_n = (-1)^{k-1} k \left(n - \dfrac{k^2-1}{2}\right)\)，其中 \(k\) 由 \(\dfrac{(k-1)k}{2} < n \le \dfrac{k(k+1)}{2}\) 确定。

第(3)问

定义：\(P_t = \{n \mid 1\le n\le t,\, a_n \mid S_n\}\)，求 \(|P_{2020}|\)。

规律：\(S_n\) 是 \(a_n\) 的整数倍当且仅当 \(a_n\) 所在组号为奇数（此时 \(a_n>0\) 且该组内 \(S_n\) 可被 \(a_n\) 整除）；偶数组内均不整除。

计算：2020 以内，完整奇数组为第 1,3,5,…,63 组，每组项数分别为 1,3,5,…,63，故满足条件的 \(n\) 的个数为 \(1+3+5+\cdots+63 = 32^2 = 1024\)。第 64 组为偶数组，其内项均不满足。

答：\(|P_{2020}| = 1024\)。

总结与验证

数列结构：第 \(k\) 组有 \(k\) 项，均为 \((-1)^{k-1}k\)；前 \(k\) 组共 \(\dfrac{k(k+1)}{2}\) 项。

(1) \(S_{2020}=1760\)（先定组再算完整组和加尾段）。

(2) \(\dfrac{(k-1)k}{2} < n \le \dfrac{k(k+1)}{2}\) 时 \(S_n = (-1)^{k-1} k \left(n - \dfrac{k^2-1}{2}\right)\)。

(3) \(|P_t|\) 为 1 到 \(t\) 内所有奇数组的项数之和；\(|P_{2020}| = 1024\)。
