数列新定义（2）集合 A+A 与 A−A

题目

(2024·北京西城·北京师大附中校考模拟预测) 已知 \(A\) 为有限个实数构成的非空集合，设 \(A + A = \{a_i + a_j \mid a_i, a_j \in A\}\)，\(A - A = \{a_i - a_j \mid a_i, a_j \in A\}\)，记集合 \(A+A\) 和 \(A-A\) 其元素个数分别为 \(|A+A|\)、\(|A-A|\)．设 \(n(A) = |A+A| - |A-A|\)．例如当 \(A = \{1,2\}\) 时，\(A+A = \{2,3,4\}\)，\(A-A = \{-1,0,1\}\)，\(|A+A| = |A-A|\)，所以 \(n(A) = 0\)．

(1) 若 \(A = \{1,3,5\}\)，求 \(n(A)\) 的值；

(2) 设 \(A\) 是由 3 个正实数组成的集合且 \((A+A) \cap A = \varnothing\)，\(A' = A \cup \{0\}\)，证明：\(n(A') - n(A)\) 为定值；

(3) 若 \(\{a_n\}\) 是一个各项互不相同的无穷递增正整数数列，对任意 \(n \in \mathbb{N}^*\)，设 \(A_n = \{a_1, a_2, \cdots, a_n\}\)，\(b_n = n(A_n)\)．已知 \(a_1 = 1,\, a_2 = 2\)，且对任意 \(n \in \mathbb{N}^*,\, b_n \geq 0\)，求数列 \(\{a_n\}\) 的通项公式．

启发引导

定义：\(A+A = \{a_i+a_j \mid a_i,a_j\in A\}\)（所有两元之和，去重），\(A-A = \{a_i-a_j \mid a_i,a_j\in A\}\)（所有两元之差，去重），\(n(A)=|A+A|-|A-A|\)。

第(2)问：可先算 \(A=\{1,3,5\}\) 的 \(n(A)\)，再勾选上方得到 \(A'\)，观察 \(n(A')-n(A)=-2\)。

第(1)问

已知：\(A=\{1, 3, 5\}\)，\(n(A)=|A+A|-|A-A|\)。

A+A：任取 \(a_i,a_j\in A\) 得 \(1+1,1+3,1+5,3+1,3+3,3+5,5+1,5+3,5+5\)，去重得 \(\{2,4,6,8,10\}\)，故 \(|A+A|=5\)。

A-A：任取两元作差得 \(0,\pm2,\pm4\)，故 \(|A-A|=5\)。

答：\(n(A)=5-5=0\)。

第(2)问

设 \(A\) 为 3 个正实数，\((A+A)\cap A=\varnothing\)，\(A'=A\cup\{0\}\)，证 \(n(A')-n(A)\) 为定值。

推导：\(A'=A\cup\{0\}\) 后，\(A'+A' = A+A \cup \{0+a,\,0+b,\,0+c,\,0+0\} = A+A \cup \{0,a,b,c\}\)。由 \((A+A)\cap A=\varnothing\) 知 \(a,b,c,0\) 均不在 \(A+A\) 中，故 \(|A'+A'| = |A+A| + 4\)。

\(A'-A' = A-A \cup \{a-0,b-0,c-0,0-a,0-b,0-c\} = A-A \cup \{\pm a,\pm b,\pm c\}\)，共新增 6 个元素，故 \(|A'-A'| = |A-A| + 6\)。

于是 \(n(A')-n(A) = (|A+A|+4)-(|A-A|+6) - (|A+A|-|A-A|) = 4-6 = -2\)。

答：\(n(A')-n(A) = -2\)（定值）。

第(3)问

\(\{a_n\}\) 递增正整数列，\(a_1=1,\,a_2=2\)，\(A_n=\{a_1,\ldots,a_n\}\)，\(b_n=n(A_n)\ge 0\)，求 \(\{a_n\}\) 通项。

结论：\(a_n = n\)。

思路：对公差为 \(d\) 的等差数列，\(|A_n+A_n|\) 与 \(|A_n-A_n|\) 随 \(n\) 增长；当 \(d>1\) 时差集增长更快，会导致 \(b_n = |A_n+A_n|-|A_n-A_n| < 0\)。只有 \(d=1\) 时恒有 \(b_n\ge 0\)，结合 \(a_1=1,\,a_2=2\) 得 \(a_n=n\)。

答：\(a_n = n\)（\(n\in\mathbb{N}^*\)）。

总结与验证

定义：\(n(A)=|A+A|-|A-A|\)，刻画“和集”与“差集”规模之差。

(1) \(A=\{1,3,5\}\) 时 \(n(A)=0\)。

(2) 三个正实数且 \((A+A)\cap A=\varnothing\) 时，\(A'=A\cup\{0\}\) 有 \(n(A')-n(A)=-2\)。

(3) 满足题设的无穷递增正整数列唯一为 \(a_n=n\)。
