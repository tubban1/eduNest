平面向量与解三角形新定义（4）n 维向量线性相关

题目

对于给定的正整数 \(n\)，记集合 \(R_n = \{\vec{\alpha} \mid \vec{\alpha} = (x_1, x_2, x_3, \cdots, x_n),\, x_j \in \mathbb{R},\, j = 1,2,3,\cdots,n\}\)，其中元素 \(\vec{\alpha}\) 称为一个n 维向量．特别地，\(\vec{0} = (0,0,\cdots,0)\) 称为零向量．

设 \(k \in \mathbb{R}\)，\(\vec{\alpha} = (a_1, a_2, \cdots, a_n) \in R_n\)，\(\vec{\beta} = (b_1, b_2, \cdots, b_n) \in R_n\)，定义加法和数乘：\(\vec{\alpha} + \vec{\beta} = (a_1+b_1, a_2+b_2, \cdots, a_n+b_n)\)，\(k\vec{\alpha} = (ka_1, ka_2, \cdots, ka_n)\)．

对一组向量 \(\vec{\alpha_1}, \vec{\alpha_2}, \cdots, \vec{\alpha_s}\)（\(s \in \mathbb{N}^+,\, s \geq 2\)），若存在一组不全为零的实数 \(k_1, k_2, \cdots, k_s\)，使得 \(k_1\vec{\alpha_1} + k_2\vec{\alpha_2} + \cdots + k_s\vec{\alpha_s} = \vec{0}\)，则称这组向量线性相关；否则，称为线性无关．

(Ⅰ) 对 \(n = 3\)，判断下列各组向量是线性相关还是线性无关，并说明理由．
① \(\vec{\alpha} = (1,1,1)\)，\(\vec{\beta} = (2,2,2)\)；
② \(\vec{\alpha} = (1,1,1)\)，\(\vec{\beta} = (2,2,2)\)，\(\vec{\gamma} = (5,1,4)\)；
③ \(\vec{\alpha} = (1,1,0)\)，\(\vec{\beta} = (1,0,1)\)，\(\vec{\gamma} = (0,1,1)\)，\(\vec{\delta} = (1,1,1)\)．

(Ⅱ) 已知向量 \(\vec{\alpha}, \vec{\beta}, \vec{\gamma}\) 线性无关，判断向量 \(\vec{\alpha}+\vec{\beta}\)，\(\vec{\beta}+\vec{\gamma}\)，\(\vec{\alpha}+\vec{\gamma}\) 是线性相关还是线性无关，并说明理由．

(Ⅲ) 已知 \(m\)（\(m \geq 2\)）个向量 \(\vec{\alpha_1}, \vec{\alpha_2}, \cdots, \vec{\alpha_m}\) 线性相关，但其中任意 \(m-1\) 个都线性无关，证明下列结论：
(ⅰ) 如果存在等式 \(k_1\vec{\alpha_1} + k_2\vec{\alpha_2} + \cdots + k_m\vec{\alpha_m} = \vec{0}\)（\(k_i \in \mathbb{R},\, i = 1,2,3,\cdots,m\)），则这些系数 \(k_1, k_2, \cdots, k_m\) 或者全为零，或者全不为零；
(ⅱ) 如果两个等式 \(k_1\vec{\alpha_1} + \cdots + k_m\vec{\alpha_m} = \vec{0}\)，\(l_1\vec{\alpha_1} + \cdots + l_m\vec{\alpha_m} = \vec{0}\)（\(k_i, l_i \in \mathbb{R},\, i = 1,2,\cdots,m\)）同时成立，其中 \(l_1 \neq 0\)，则 \(\frac{k_1}{l_1} = \frac{k_2}{l_2} = \cdots = \frac{k_m}{l_m}\)．

启发引导

题意拆解：线性相关即存在不全为零的 \(k_1,\ldots,k_s\) 使 \(k_1\vec{\alpha_1}+\cdots+k_s\vec{\alpha_s}=\vec{0}\)；否则线性无关。

(Ⅰ) ① 两向量成比例则相关。② 含成比例的两向量则整组相关。③ \(R_3\) 中 4 个向量必相关（维数 3）。

(Ⅱ) 设 \(k_1(\vec{\alpha}+\vec{\beta})+k_2(\vec{\beta}+\vec{\gamma})+k_3(\vec{\alpha}+\vec{\gamma})=\vec{0}\)，整理成 \(\alpha,\beta,\gamma\) 的线性组合，由 \(\alpha,\beta,\gamma\) 无关得系数全为 0，解出 \(k_1=k_2=k_3=0\)。

(Ⅲ) (ⅰ) 若某 \(k_i=0\) 则其余 \(m-1\) 个向量线性组合为 0，由“任意 \(m-1\) 个无关”得其余系数全 0。(ⅱ) 由两式用 \(l_1\neq 0\) 消元得 \(k_i/l_i\) 相等。

拿分策略：(Ⅰ) 成比例⇒相关；含相关子集⇒整组相关；\(R_3\) 中 4 个向量必相关。(Ⅱ) 设组合为 0，整理成 \(\alpha,\beta,\gamma\) 的线性组合，由无关得系数全 0 解出 \(k_1=k_2=k_3=0\)。(Ⅲ)(ⅰ) 反证或分情况：某 \(k_i=0\)⇒其余全 0；(ⅱ) 用 \(l_1\neq 0\) 解出 \(\alpha_1\) 代入另一式得比例。

考点：线性相关定义、维数、唯一表示。易错：线性相关是“存在不全为零的系数”，无关是“仅当系数全为零”；(Ⅲ)(ⅰ) 用“任意 \(m-1\) 个无关”推出若某 \(k_i=0\) 则其余必全 0。

第(Ⅰ)问

设元：\(n=3\)，按定义：存在不全为零的实数使线性组合为 \(\vec{0}\) 则相关，否则无关。

① 列式与答：\(\vec{\beta}=(2,2,2)=2\vec{\alpha}\)，故 \(2\vec{\alpha}+(-1)\vec{\beta}=\vec{0}\)，系数不全为零，\(\boxed{\text{线性相关}}\)。

② 列式与答：\(\vec{\alpha}\) 与 \(\vec{\beta}\) 线性相关，故存在不全为零的 \(k_1,k_2\) 使 \(k_1\vec{\alpha}+k_2\vec{\beta}=\vec{0}\)，取 \(k_3=0\) 即得 \(k_1\vec{\alpha}+k_2\vec{\beta}+0\cdot\vec{\gamma}=\vec{0}\)，整组 \(\boxed{\text{线性相关}}\)。

③ 列式与答：\(R_3\) 维数为 3，至多 3 个向量线性无关，4 个向量必线性相关，故 \(\boxed{\text{线性相关}}\)。

第(Ⅱ)问

设元：设 \(k_1(\vec{\alpha}+\vec{\beta})+k_2(\vec{\beta}+\vec{\gamma})+k_3(\vec{\alpha}+\vec{\gamma})=\vec{0}\)。

列式：整理得 \((k_1+k_3)\vec{\alpha}+(k_1+k_2)\vec{\beta}+(k_2+k_3)\vec{\gamma}=\vec{0}\)。因 \(\vec{\alpha},\vec{\beta},\vec{\gamma}\) 线性无关，故 \(k_1+k_3=0\)，\(k_1+k_2=0\)，\(k_2+k_3=0\)。

化简：前两式得 \(k_2=k_3\)，代入 \(k_2+k_3=0\) 得 \(2k_2=0\)，故 \(k_2=k_3=0\)，进而 \(k_1=0\)。

答：仅当 \(k_1=k_2=k_3=0\) 时成立，故 \(\vec{\alpha}+\vec{\beta}\)，\(\vec{\beta}+\vec{\gamma}\)，\(\vec{\alpha}+\vec{\gamma}\) \(\boxed{\text{线性无关}}\)。

第(Ⅲ)问

设元：\(m\) 个向量线性相关，任意 \(m-1\) 个线性无关；存在 \(k_1,\ldots,k_m\) 不全为零使 \(k_1\vec{\alpha_1}+\cdots+k_m\vec{\alpha_m}=\vec{0}\)。

(ⅰ) 列式与化简：若某 \(k_i=0\)（如 \(k_1=0\)），则 \(k_2\vec{\alpha_2}+\cdots+k_m\vec{\alpha_m}=\vec{0}\)。因 \(\vec{\alpha_2},\ldots,\vec{\alpha_m}\) 线性无关，故 \(k_2=\cdots=k_m=0\)，从而 \(k_1,\ldots,k_m\) 全为零。若存在非零系数，则不能只有部分为零（否则将非零项移到一边得少于 \(m\) 个向量的非零组合为 \(\vec{0}\)，与“任意 \(m-1\) 个无关”矛盾），故系数要么全为零要么全不为零。

(ⅱ) 列式与化简：由 \(l_1\neq 0\) 得 \(\vec{\alpha_1}=-\frac{l_2}{l_1}\vec{\alpha_2}-\cdots-\frac{l_m}{l_1}\vec{\alpha_m}\)。代入 \(k_1\vec{\alpha_1}+\cdots+k_m\vec{\alpha_m}=\vec{0}\) 得 \(\bigl(k_2-k_1\frac{l_2}{l_1}\bigr)\vec{\alpha_2}+\cdots+\bigl(k_m-k_1\frac{l_m}{l_1}\bigr)\vec{\alpha_m}=\vec{0}\)。\(\vec{\alpha_2},\ldots,\vec{\alpha_m}\) 线性无关，故 \(k_2-k_1\frac{l_2}{l_1}=0,\ldots,k_m-k_1\frac{l_m}{l_1}=0\)，即 \(\frac{k_1}{l_1}=\frac{k_2}{l_2}=\cdots=\frac{k_m}{l_m}\)。

答：(ⅰ) 系数 \(k_1,\ldots,k_m\) 全为零或全不为零；(ⅱ) \(\dfrac{k_1}{l_1}=\dfrac{k_2}{l_2}=\cdots=\dfrac{k_m}{l_m}\)。

总结与验证

回顾：(Ⅰ)① 成比例故相关；② 含相关子集故相关；③ 4 个三维向量必相关。(Ⅱ) 设组合为 0 推出 \(k_1=k_2=k_3=0\) 故无关。(Ⅲ)(ⅰ) 某系数为 0 则其余全 0；(ⅱ) 代入消元得 \(\frac{k_1}{l_1}=\cdots=\frac{k_m}{l_m}\)。

易错：线性相关是“存在不全为零的系数”，无关是“仅当系数全为零”；(Ⅲ)(ⅰ) 用“任意 \(m-1\) 个无关”推出若某 \(k_i=0\) 则其余必全 0。
