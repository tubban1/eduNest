圆锥曲线新定义（2）椭圆焦半径与准线

题目

(2024·贵州贵阳·高三统考期末) 阅读材料：在平面直角坐标系中，若点 \(M(x,y)\) 与定点 \(F(c,0)\)（或 \(F'(-c,0)\)）的距离和它到定直线 \(l: x = \frac{a^2}{c}\)（或 \(l': x = -\frac{a^2}{c}\)）的距离之比是常数 \(\frac{c}{a}\)（\(0 < c < a\)），则 \(\frac{\sqrt{(x-c)^2+y^2}}{\frac{a^2}{c} - x} = \frac{c}{a}\)，化简可得 \(\frac{x^2}{a^2} + \frac{y^2}{a^2-c^2} = 1\)．设 \(b^2 = a^2 - c^2\)（\(b > 0\)），则得到方程 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)），所以点 \(M\) 的轨迹是一个椭圆．这里定点 \(F(c,0)\) 是椭圆的一个焦点，直线 \(l: x = \frac{a^2}{c}\) 称为相应于焦点 \(F\) 的准线；定点 \(F'(-c,0)\) 是椭圆的另一个焦点，直线 \(l': x = -\frac{a^2}{c}\) 称为相应于焦点 \(F'\) 的准线．根据椭圆的这个定义，若点 \(M(x,y)\) 在椭圆 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）上，\(F(c,0)\) 是椭圆的右焦点，椭圆的离心率 \(e = \frac{c}{a}\)，则点 \(M\) 到准线 \(l: x = \frac{a^2}{c}\) 的距离为 \(\frac{a^2}{c} - x\)，所以 \(|MF| = \frac{c}{a}\left(\frac{a^2}{c} - x\right) = a - ex\)，我们把这个公式称为椭圆的焦半径公式．

结合阅读材料回答下面的问题：已知椭圆 \(C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)（\(a > b > 0\)）的右焦点为 \(F\)，点 \(P\) 是该椭圆上第一象限的点，且 \(PF \perp x\) 轴，若直线 \(l: x = 9\) 是椭圆右准线方程，点 \(P\) 到直线 \(l\) 的距离为 8．

(1) 求点 \(P\) 的坐标；

(2) 若点 \(M\)、\(N\) 也在椭圆 \(C\) 上且 \(\triangle MNP\) 的重心为 \(F\)，判断 \(|FM|,\, |FP|,\, |FN|\) 是否能构成等差数列？如果能，求出该等差数列的公差，如果不能，说明理由．

题意拆解

题目在问：已知椭圆右准线 \(x=9\)、点 \(P\) 在椭圆上且 \(PF\perp x\) 轴、\(P\) 到准线距离为 8，(1) 求点 \(P\) 的坐标；(2) 判断 \(|FM|,\,|FP|,\,|FN|\) 能否成等差数列（\(M,N\) 在椭圆上且 \(\triangle MNP\) 的重心为 \(F\)），若能求公差。

启发思路

本题考查椭圆第二定义（焦点、准线）与焦半径公式 \(|MF| = a - ex\)，以及重心与等差数列。

  • 右准线：\(x = \frac{a^2}{c}\)，题中为 \(x = 9\)
  • P 在椭圆上且 PF ⊥ x 轴：P 与 F 横坐标相同，即 \(x_P = c\)
  • P 到准线距离为 8：\(9 - x_P = 8 \Rightarrow c = 1\)，再由 \(a^2/c=9\) 得 \(a^2=9\)

涉及知识点

  • 椭圆第二定义（到焦点与到准线距离之比为离心率 \(e=c/a\)）
  • 焦半径公式 \(|MF| = a - ex\)（右焦点）
  • 三角形重心坐标公式
  • 等差数列的充要条件（三项成等差 \(\Leftrightarrow\) 中间项的二倍等于另两项之和）

考点与易错

考点：椭圆第二定义、焦半径公式、重心坐标、等差数列。易错：\(P\) 到准线距离为 \(a^2/c-x_P\)，题中等于 8 得 \(c=1\)；公差 \(d\) 随 \(M,N\) 变化，答案中需说明或举例。

(1) 求点 \(P\) 的坐标

条件梳理

右准线 \(l: x = 9\)，即 \(\frac{a^2}{c} = 9\)．点 \(P\) 在第一象限且 \(PF \perp x\) 轴，故 \(P\) 与 \(F(c,0)\) 横坐标相同：\(x_P = c\)．点 \(P\) 到准线 \(l\) 的距离为 8，即 \(9 - x_P = 8\)，得 \(x_P = 1\)，所以 \(c = 1\)．

求 \(a,\,b\)

由 \(\frac{a^2}{c} = 9\) 且 \(c=1\) 得 \(a^2 = 9\)，\(a = 3\)．又 \(b^2 = a^2 - c^2 = 9 - 1 = 8\)，\(b = 2\sqrt{2}\)．椭圆方程为 \(\frac{x^2}{9} + \frac{y^2}{8} = 1\)．

求 \(y_P\)

\(P(c, y_P) = (1, y_P)\) 在椭圆上且 \(y_P > 0\)：

\[\frac{1}{9} + \frac{y_P^2}{8} = 1 \Rightarrow \frac{y_P^2}{8} = \frac{8}{9} \Rightarrow y_P^2 = \frac{64}{9} \Rightarrow y_P = \frac{8}{3}.\]

故点 \(P\) 的坐标为 \(\boxed{(1,\, \frac{8}{3})}\)．

答：(1) 点 \(P\) 的坐标为 \(\left(1,\, \frac{8}{3}\right)\)．

图形

(2) \(|FM|,\,|FP|,\,|FN|\) 是否成等差数列

重心条件

\(\triangle MNP\) 的重心为 \(F(1,0)\)，即

\[\frac{x_M + x_N + 1}{3} = 1,\quad \frac{y_M + y_N + \frac{8}{3}}{3} = 0,\]

得 \(x_M + x_N = 2\)，\(y_M + y_N = -\frac{8}{3}\)．

焦半径公式

\(e = \frac{c}{a} = \frac{1}{3}\)．对椭圆上任意点 \((x,y)\)，到右焦点 \(F(1,0)\) 的焦半径 \(|MF| = a - ex = 3 - \frac{x}{3}\)．故

\[|FM| = 3 - \frac{x_M}{3},\quad |FN| = 3 - \frac{x_N}{3},\quad |FP| = 3 - \frac{1}{3} = \frac{8}{3}.\]

是否成等差

三项 \(|FM|,\,|FP|,\,|FN|\) 成等差数列当且仅当 \(2|FP| = |FM| + |FN|\)．

\[|FM| + |FN| = \left(3 - \frac{x_M}{3}\right) + \left(3 - \frac{x_N}{3}\right) = 6 - \frac{x_M+x_N}{3} = 6 - \frac{2}{3} = \frac{16}{3},\]

而 \(2|FP| = 2 \cdot \frac{8}{3} = \frac{16}{3}\)，故 \(2|FP| = |FM| + |FN|\) 恒成立．所以能构成等差数列．

求直线 MN 与 M、N 坐标

延长 \(PF\) 交 \(MN\) 于 \(D\)，由重心及 \(P(1,\frac{8}{3})\)、\(F(1,0)\) 可知 \(D\) 为 \(MN\) 中点，且 \(|PF|=2|FD|\)，得 \(D(1,\,-\frac{4}{3})\)．由 \(y_M+y_N=-\frac{8}{3}\) 知 \(D\) 纵坐标为 \(\frac{y_M+y_N}{2}=-\frac{4}{3}\)，与上一致．

\(M(x_1,y_1)、N(x_2,y_2)\) 在椭圆上：\(\frac{x_1^2}{9}+\frac{y_1^2}{8}=1\)，\(\frac{x_2^2}{9}+\frac{y_2^2}{8}=1\)．两式相减得 \(\frac{x_1^2-x_2^2}{9}+\frac{y_1^2-y_2^2}{8}=0\)，即 \(\frac{(x_1+x_2)(x_1-x_2)}{9}+\frac{(y_1+y_2)(y_1-y_2)}{8}=0\)．代入 \(x_1+x_2=2\)、\(y_1+y_2=-\frac{8}{3}\) 得 \(\frac{2}{9}(x_1-x_2)-\frac{8/3}{8}(y_1-y_2)=0\)，故 \(\frac{y_1-y_2}{x_1-x_2}=\frac{2}{3}\)，即 \(k_{MN}=\frac{2}{3}\)．

直线 \(MN\) 过 \(D(1,-\frac{4}{3})\)，斜率 \(\frac{2}{3}\)：\(y+\frac{4}{3}=\frac{2}{3}(x-1)\)，即 \(y=\frac{2}{3}x-2\)．与椭圆 \(\frac{x^2}{9}+\frac{y^2}{8}=1\) 联立，代入 \(y=\frac{2}{3}x-2\) 得 \(\frac{x^2}{9}+\frac{(\frac{2}{3}x-2)^2}{8}=1\)，化简得 \(x^2-2x-3=0\)，解得 \(x=-1\) 或 \(x=3\)．即 \(M、N\) 的横坐标为 \(-1\) 与 \(3\)（顺序可互换）．

两种情况的公差

焦半径 \(|MF|=3-\frac{x}{3}\)．当 \(x=-1\) 时对应点到 \(F\) 的距离为 \(3-\frac{-1}{3}=\frac{10}{3}\)；当 \(x=3\) 时对应点到 \(F\) 的距离为 \(3-\frac{3}{3}=2\)．\(|FP|=\frac{8}{3}\)．

故 \(|FM|,\,|FP|,\,|FN|\) 成等差数列时，有两种可能：

  • 情况一：\(|FM|=\frac{10}{3},\,|FP|=\frac{8}{3},\,|FN|=2\)，公差 \(d = \frac{8}{3}-\frac{10}{3} = -\frac{2}{3}\)；
  • 情况二：\(|FM|=2,\,|FP|=\frac{8}{3},\,|FN|=\frac{10}{3}\)，公差 \(d = \frac{8}{3}-2 = \frac{2}{3}\)．
答：(2) 能构成等差数列．答案有两个：① \(|FM|=\frac{10}{3},\,|FP|=\frac{8}{3},\,|FN|=2\)，公差 \(d=-\frac{2}{3}\)；② \(|FM|=2,\,|FP|=\frac{8}{3},\,|FN|=\frac{10}{3}\)，公差 \(d=\frac{2}{3}\)．

总结与验证

解题思路
  1. (1) 用准线 \(x=9\) 与 P 到准线距离 8 得到 \(c=1\)、\(a^2=9\)，再求 \(b^2\) 及 P 纵坐标．
  2. (2) 用重心条件得 \(x_M+x_N=2,\,y_M+y_N=-8/3\)；由点差得 \(k_{MN}=2/3\)，直线 MN 过 \(D(1,-4/3)\) 与椭圆联立得 \(x=-1\) 或 \(3\)，故 \(|FM|,\,|FP|,\,|FN|\) 成等差数列，答案有两个：公差 \(d=-\frac{2}{3}\)（对应 10/3, 8/3, 2）或 \(d=\frac{2}{3}\)（对应 2, 8/3, 10/3）．
易错提醒

准线方程 \(x=a^2/c=9\) 与 \(c=1\) 推出 \(a^2=9\)；焦半径是 \(a-ex\)（右焦点），不要写成 \(a+ex\)；三项成等差用 \(2|FP|=|FM|+|FN|\) 验证．易错：第(2)问 M、N 由直线与椭圆唯一确定，公差只有两种可能 \(d=\frac{2}{3}\) 或 \(d=-\frac{2}{3}\)，需写出两个答案．

验证

\(P(1,8/3)\) 在椭圆 \(\frac{x^2}{9}+\frac{y^2}{8}=1\) 上：\(\frac{1}{9}+\frac{64/9}{8}=\frac{1}{9}+\frac{8}{9}=1\)．\(|FP|=8/3\)，与焦半径 \(a-ex=3-1/3=8/3\) 一致．
