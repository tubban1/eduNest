数列新定义（4）周期数列

题目

(2024·全国·高三专题练习) 对于无穷数列 \(\{a_n\}\)，若存在正整数 \(T\)，使得 \(a_{n+T} = a_n\) 对一切正整数 \(n\) 都成立，则称无穷数列 \(\{a_n\}\) 是周期为 \(T\) 的周期数列．

(1) 已知无穷数列 \(\{a_n\}\) 是周期为 2 的周期数列，且 \(a_1 = 3\)，\(a_2 = 1\)，\(S_n\) 是数列 \(\{a_n\}\) 的前 \(n\) 项和，若 \(\frac{S_n}{n} \leq t\) 对一切正整数 \(n\) 恒成立，求常数 \(t\) 的取值范围；

(2) 若无穷数列 \(\{a_n\}\) 和 \(\{b_n\}\) 满足 \(b_n = a_{n+1} - a_n\)，求证：“\(\{a_n\}\) 是周期为 \(T\) 的周期数列”的充要条件是“\(\{b_n\}\) 是周期为 \(T\) 的周期数列，且 \(\sum_{i=1}^{T} b_i = 0\)”；

(3) 若无穷数列 \(\{a_n\}\) 和 \(\{b_n\}\) 满足 \(b_n = a_{n+1} - a_n\)，且 \(b_1 = 1,\, b_2 = a,\, b_{n+2} = \frac{b_{n+1}}{b_n}\)（\(n \geq 1,\, n \in \mathbb{N}\)），是否存在非零常数 \(a\)，使得 \(\{a_n\}\) 是周期数列？若存在，请求出所有满足条件的常数 \(a\)；若不存在，请说明理由．

启发引导

周期概念：数列的值像时钟一样循环，即 \(a_{n+T} = a_n\)。
本例：序列 3, 1, 3, 1, 3, 1…（周期 \(T=2\)）。

平均值 \(\dfrac{S_n}{n}\)：
\(n=1\)：\(\dfrac{S_1}{1}=\dfrac{3}{1}=3\)
\(n=2\)：\(\dfrac{S_2}{2}=\dfrac{3+1}{2}=2\)
\(n=3\)：\(\dfrac{S_3}{3}=\dfrac{7}{3}\approx 2.33\)
随着 \(n\) 增大，\(\dfrac{S_n}{n}\) 趋于一个周期内的平均 \((3+1)/2=2\)，最大值在 \(n=1\) 时取得，为 3。

第(1)问

周期为 2，\(a_1=3,\,a_2=1\)，求使 \(\dfrac{S_n}{n}\le t\) 对一切 \(n\in\mathbb{N}^*\) 成立的常数 \(t\) 的取值范围。

分析：\(a_n\) 以 3,1,3,1,… 循环，\(S_n\) 为前 \(n\) 项和。当 \(n=2m\) 时 \(S_n = 4m\)，\(\dfrac{S_n}{n}=2\)；当 \(n=2m-1\) 时 \(S_n = 4m-3\)，\(\dfrac{S_n}{n} = \dfrac{4m-3}{2m-1} = 2 - \dfrac{1}{2m-1}\)，随 \(m\) 增大趋于 2，在 \(m=1\) 时最大：\(\dfrac{S_1}{1}=3\)。

故 \(\dfrac{S_n}{n}\) 的最大值为 3（在 \(n=1\) 取到），要对一切 \(n\) 成立 \(\dfrac{S_n}{n}\le t\)，需 \(t\ge 3\)。

答：\(t \in [3,+\infty)\)。可用下方滑块验证：\(t<3\) 时 \(n=1\) 不满足。

第(2)问

\(b_n = a_{n+1}-a_n\)，求证：“\(\{a_n\}\) 为周期 \(T\) 的周期数列”当且仅当“\(\{b_n\}\) 为周期 \(T\) 的周期数列且 \(\sum_{i=1}^T b_i = 0\)”。

充分性：若 \(a_{n+T}=a_n\)，则 \(b_{n+T}=a_{n+T+1}-a_{n+T}=a_{n+1}-a_n=b_n\)，且 \(a_{T+1}-a_1 = \sum_{i=1}^T b_i\)，由 \(a_{T+1}=a_1\) 得 \(\sum_{i=1}^T b_i=0\)。

必要性：若 \(b_n\) 周期为 \(T\) 且 \(\sum_{i=1}^T b_i=0\)，则 \(a_{n+T} = a_n + \sum_{i=1}^T b_{n+i-1} = a_n + \sum_{i=1}^T b_i = a_n\)，故 \(\{a_n\}\) 周期为 \(T\)。

第(3)问

\(b_1=1,\,b_2=a,\,b_{n+2}=\dfrac{b_{n+1}}{b_n}\)，问是否存在非零常数 \(a\) 使 \(\{a_n\}\)（满足 \(b_n=a_{n+1}-a_n\)）为周期数列。

递推：由 \(b_{n+2}=b_{n+1}/b_n\) 得 \(b_3=a,\,b_4=1,\,b_5=1/a,\,b_6=1/a,\,b_7=1,\,b_8=a,\ldots\)，\(b_n\) 呈周期 6（当 \(a\ne 0\)）。要使 \(\{a_n\}\) 周期，由 (2) 需 \(\sum_{i=1}^T b_i=0\)。对周期 6 计算 \(\sum_{i=1}^6 b_i = 1+a+a+1+1/a+1/a = 2+2a+2/a\)，令其为 0 得 \(a+1/a = -1\)，即 \(a^2+a+1=0\)，无实根。故不存在满足条件的非零实数 \(a\)（若允许复数则 \(a\) 为 \(a^2+a+1=0\) 的根）。

总结与验证

(1) 周期 2、\(a_1=3,a_2=1\) 时 \(\dfrac{S_n}{n}\) 最大为 3，故 \(t\ge 3\)。

(2) \(b_n=a_{n+1}-a_n\) 时：\(\{a_n\}\) 周期 \(T\) \(\Leftrightarrow\) \(\{b_n\}\) 周期 \(T\) 且 \(\sum_{i=1}^T b_i=0\)。

(3) \(b_{n+2}=b_{n+1}/b_n\) 且 \(b_1=1,\,b_2=a\) 时，\(b_n\) 周期 6；\(\sum_{i=1}^6 b_i=0\) 要求 \(a^2+a+1=0\)，无实根，故不存在使 \(\{a_n\}\) 为周期数列的非零实数 \(a\)。
